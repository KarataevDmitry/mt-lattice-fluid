# Глоссарий · человеческий язык ↔ репозиторий

Короткие подписи для книги, MODEL и чатов. **Имена в коде и JSON** меняются только с миграцией и verify.

| По-русски | В репо (код / служебное) | Смысл |
|-----------|--------------------------|--------|
| **Шаблон соседства** | поле `stencil`, `for_stencil`, `n4` / `hex` / `fcc` | Какие соседи у клетки: N₄ (архив), гекс N₆ (срез 2+1), FCC N₁₂ (3+1). **Кто входит в локальное обновление**, не CUDA и не Wolfram-stencil. |
| **Локальное обновление по соседям** | `neighbor_sum`, `linear_step`, `roll` по осям | Один шаг: значение в клетке из себя и соседей по выбранному шаблону. |
| **Правило эволюции** | `g`, leapfrog, `MConfig`, `update` | Ваш закон M, не универсальный CA-движок. |
| **Единый источник истины (физика)** | SSOT → `MODEL.md` + `model/` | Где записан контракт теории. Слово SSOT — **внутри репо**, в прозе книги: «источник формул». |
| **Единый источник (сцена симуляции)** | `mt_ca.app` — habitat, scenario, `RunSpec` | Что на решётке до тиков; не путать с физическим SSOT. |
| **Океан** | `VACUUM_BOIL`, первая поверхность | Решётка до возбуждений. |
| **Одеяло (МЗВ)** | `mt_ca.blanket` | Вторая поверхность над океаном. |
| **Угловой шаблон** (гравитация) | в MODEL бывш. «stencil θ_f» | Явные углы на FCC-тетраэдрах / Regge-дефицит — **открытый** кусок §8.4, не то же, что `stencil=hex`. |
| **Символика окрестности FCC** | `mt_ca.analysis.stencil_symbol` (имя модуля legacy) | $\sum_{\delta\in N_{12}} e^{2\pi i k\cdot\delta}$ на торе; проверка, не T-слой. |
| **Верификация** | `verify_principles.py`, `verify_checks/suites.py` | Снимок «MODEL ↔ код»; `--ship`, `--suite`, `--scenario` (id как у `mt_ca.app`). |
| **Журнал разработки** | `DEVLOG.md` | Даты, impl, open leaves — не физика. |

**Правило для текста:** в `model/` и книге — левая колонка; в Python и yaml — правая, пока не сделана явная миграция.
