### 2.1 Детерминизм M → иллюзия «квантовой случайности» на T

**`g` строго детерминирована:** нет RNG, нет `rand()` в **`projected_step_fixed`**.  
`z(x,t+1) = g({z(y,t)}_{y∈N(x)})` — **100% функция** прошлого (A2).

**Откуда тогда вероятность в T / QM?**

1. **Динамический хаос из детерминизма** — gate `𝒩(z)` + mixing (A5, A6): микроскопическое отличие фаз на t=0 → через O(1) тиков непредсказуемый **узор** на M; macro = «белый шум» вакуума.
2. **Грубый прибор** — наблюдатель не читает одну ячейку `v_p`; **binomial (1-2-1) macro readout** по **≫1** ячеек (§4.1). Суммирование детерминированных фаз → **интерференция** → волновое описание; `|Φ|²` на T = **статистика** macro-фильтра, не dice в `g`.

```
M: детерминированный CA, каждый тик вычислим
T: |Ψ|², Born — термодинамика + масштаб наблюдения, не фундаментальный random
```

**Эйнштейн-позиция в модели:** «Бог не играет в кости» на M; кости — **UI T**, если прибор грубее `hL`.

### 2.3 Теорема 2.3 · тепловая смерть M **невозможна** · вселенная **не выключается**

**Статус:** доказательство **conditional** — из §0, **A3**, **A5**, **A6**, **A13**, §3.12, §4.1–§4.1.2. Не claim о реальной Вселенной; не заменяет sim на полной **`Λ`**.

#### Определения

| | |
|---|---|
| **D1 · shutdown** | существует **`t`** без шага **`g`**, или **`hT → ∞`**, или **`g`** меняется / обнуляется |
| **D2 · M heat death** | **`Σ_x |z|² → 0`** **или** глобально **`z ≡ 0`** устойчиво **или** **`g(Ψ)=Ψ`** с «мёртвым» вакуумом без A5-кипения |
| **D3 · T heat death** | macro-readout **`Φ = ℬz`** теряет структуру (контраст **`Var(Φ) → 0`**) при **`Σ|z|²`** на M **≈ const** |

**ℬ** — binomial readout §4.1: **`Φ = (1-2-1)^{⊗2·R} z`**. На **`R ≥ 1`** ядро **не** инъективно.

#### Лемма 2.3.1 (нет shutdown)

**Claim:** при §0.3 для **всех** **`t ∈ ℤ`**: **`Ψ^{t+1} = g(Ψ^t)`**, **`hT`**, **`g`** const.

**Доказательство.** Постулат 0.3 **определяет** M как КА с одним **`hT`** на тик. «Выключить» = нарушить §0.3. ∎

#### Лемма 2.3.2 (сохранение информации)

**Claim:** **`N(t) := Σ_x z†z(x,t)`** — invariant: **`N(t+1) = N(t)`** для всех **`t`**.

**Доказательство.**

1. **A3** + §3.2: **`g = g_nonlin ∘ g_lin`**; **`g_lin`** — product локальных unitaries на **`N`**; **`g_nonlin`** — **`R(Φ)`** / **`exp(iΦ)`** (§3.10.3, §3.12.5) — unitary на **`ℂ²`**, не умножает модуль.
2. Product unitaries сохраняют **`N`** на каждом шаге.
3. Индукция по **`t`**: **`N(t) = N(0)`** для всех **`t`**. ∎

**Следствие 2.3.2a:** **`N → 0`** на M **невозможно**, если **`N(0) > 0`**. «Информация сгорела» в смысле **A3** — **ложь**.

#### Лемма 2.3.3 (A6 не отменяет A3)

**Claim:** **A6** (локальная фазовая энтропия **не убывает** на ε) **не** implies **`N → 0`**.

**Доказательство.** A6 — **перераспределение** фазы при **фиксированной** норме (§3.2: mixing при fixed norm). **A3** фиксирует **`N`**. Локальный рост энтропии = микширование, не dissipation в **`g`**. ∎

#### Лемма 2.3.4 (нет терморавновесия **`z ≡ 0`**)

**Claim:** **`z(x,t) ≡ 0`** **не** устойчивое термодинамическое состояние канонического **`g`**.

**Доказательство.**

1. **A5:** минимум **`V(|z|²)`** **не** в **`z = 0`** (§3.3); при **`|z| → 0`** gate **`Φ → large`** (§3.2, A5 row).
2. §10.2: при **`z = 0`** **`z·exp(iΦ) = 0`** — локальный **deadlock**; A5 **запрещает** трактовать это как физический вакуум: вакуум = **осциллирующий фон**, **`ρ_field > 0`** (§5.0, A5).
3. Любое A5-согласованное начальное условие (**`|z| ~ vacuum_amplitude > 0`**) порождает **permanent micro-кипение**; **`z ≡ 0`** **недостижим** как глобальный attractor (**A5 = 3-й закон**).
4. Вместе с 2.3.2a: **D2** (M heat death через **`N → 0`** или устойчивый **`z ≡ 0`**) **невозможен**. ∎

#### Лемма 2.3.5 (micro обратимость)

**Claim:** канонический **`g`** на **`Z_N[i]`** (§3.12) **обратим**: **`∃ g⁻¹`**, **`g⁻¹(g(Ψ)) = Ψ`**.

**Доказательство.** **A13** + §3.12.3: leapfrog **`Z⁺ + Z⁻ = 2Z + ⌊𝒩⌋`**; reverse **`Z⁻ = 2Z + ⌊𝒩⌋ − Z⁺`**. Kick ledger + swap **`(Z_t, Z_{t−1})`**. Bit-exact на **`ℤ`**. ∎

#### Лемма 2.3.6 (T readout необратим)

**Claim:** **`ℬ`** (§4.1) **не** инъективна при **`R ≥ 1`**: **`∃ z₁ ≠ z₂`**, **`ℬz₁ = ℬz₂`**.

**Доказательство.** **`ℬ`** — separable conv с ядром **`[1,2,1]/4`**, **`R`** passes. Kernel has non-trivial null space on finite **`Λ`**: distinct micro-конфигурации с одинаковым blur → один **`Φ`**. Macro-восстановление **`z`** из **`Φ`** **не** unique. ∎

#### Предложение 2.3.7 (T heat death **не** нарушает M)

**Claim:** **`ν_CA`-затухание** **`Φ`** (§4.1.2) — **не** член в **`g`**; **`N`** на M invariant (2.3.2).

**Доказательство.** §4.1.2: **`ν_CA ∇²Φ`** добавляется **только** в T-equation после binomial **`ℬ`**. На M: **`g`** **без** **`ν∇²z`** (§4.1.2 impl table). Macro drain = **перекачка в micro-кипение A5** при **фиксированном **`N`**** (2.3.3). **D3** (T heat death) **совместим** с **¬D2** (M heat death). ∎

#### Определение 2.3.8-pre (frozen / non-boiling)

| | |
|---|---|
| **D4 · frozen tick** | **`⌊𝒩(Ψ)⌋ ≡ 0`** на всём **`Λ`** (§3.12.5) |
| **D5 · global fixed point** | **`g(Ψ*) = Ψ*`** при symmetric history **`(Z_t,Z_{t−1})=(Z*,Z*)`** ⟺ **D4** на **`Ψ*`** (§3.12.3) |

**A5-кипение** = **¬D4** на positive measure **`Λ`** **или** temporal churn (**`Ψ^{t+1}≠Ψ^t`**) при **`N≈const`**. «Мёртвый» вакуум в **D2** = **D5** без A5-фона.

#### Лемма 2.3.8a (классификация fixed points)

**Claim:** **D5** ⟺ **`z(x,t) ≡ c`** на всём торе **`Λ`** (§10.1), **`c ∈ Z_N[i]`** (включая **`c=0`**).

**Доказательство.**

**⟹.** Symmetric leapfrog **`Z⁺+Z⁻=2Z+⌊𝒩⌋`** при **`Z⁺=Z⁻=Z*`** ⇒ **`⌊𝒩(Z*)⌋=0`**. По §3.12.5 **`⌊𝒩⌋=0`** ⇒ **`Φ=0`** (mod **`N_ring`**) ⇒ **`ζ_imag=0`** (числитель **`K_P·ζ_imag`**). Holonomy §3.12.5:

```
ζ_imag ∝ ⟨V⟩U − ⟨U⟩V   ⇒   discrete CR на каждой ячейке
```

§3.9.1: **`Δ_disc z=0`** ⟺ **`z(x)=⟨z⟩_{N(x)}`**. На **связном** торе (§10.1) — **дискретная гармоничность**. **Maximum principle** на конечном графе: если **`z(x₀)`** = avg соседей и соседи не все равны **`z(x₀)`**, поток нарушает равенство; индукция по расстоянию ⇒ **`z(x)≡c`**. ∎

**⟸.** **`z≡c`**: **`Σ_N z ∝ c`**, **`ζ_imag=0`**, **`Φ=0`**, **`⌊𝒩⌋=0`**, leapfrog identity. ∎

#### Лемма 2.3.8b (A5/A6 исключают физические fixed points)

**Claim:** ни одна конфигурация из **2.3.8a** **не** входит в **A5-физическое** состояние (вакуум / admissible **`t=0`**).

**Доказательство.**

| класс | почему excluded |
|-------|-----------------|
| **`c=0`** | §10.2: **`z·exp(iΦ)=0`** — deadlock; A5: **`z≡0`** не вакуум |
| **`c≠0` static** | **A5** §5.0: вакуум = **`ρ_field>0`** **кипящий** фон, не frozen holomorphy; **A6** §3.2: «**замёрзшие** фазы» запрещены; §3.7.2: **`Δφ_min`** + gate — micro-динамика, не global rest |

**Следствие:** **D5** без A5-кипения = **только** математические константы, **все** rejected физикой §0/A5/A6. **Пусто** в admissible state space. ∎
