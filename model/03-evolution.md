# §3 · Функция перехода g

### 3.1 Каркас

Дискретность **`Λ`**, **`(hL, hT)`** — **Теорема 0.1** (§0). Локальность и каузальность:

```
Ψ^{t+1} = g(Ψ^t)
g = g_nonlin ∘ g_lin
g_lin : z ↦ L(z) — линейное смешивание по N(x)
g_nonlin: z ↦ z · exp(i·Φ(z)) — локальная фаза
```

```
N(x) = { x ± ê_i } — первая координационная оболочка (A1)
(Δ₄ z)(x) = Σ_{y∈N(x)} ( z(y) - z(x) )
```

Вторая координационная оболочка за один **`hT`** запрещена (**A1**); neighborhood Moore не используется.

На каркасе параметры не фиксируются:

| параметр | где закрывается |
|----------|-----------------|
| **`γ`** | §3.12, §5.2 |
| форма **`Φ`** | §3.12.5 |
| **`L`**: unitary vs diffusive | §3.12 |
| **`r`, `1+r`** | §7.1 |
| **`ε`** | A7, §7.1 |

### 3.9 Дискретный анализ

#### 3.9.1 Голоморфная среда

Решётка **FCC N₁₂** / срез **гекс N₆**; поле **`z ∈ ℂ²`** (§3.10).

Линейный предел (идеальный вакуум):

```
Δ_disc z = 0 ⟺ z(x) = (1/|N|) Σ_{y∈N(x)} z(y) = ⟨z⟩_N
```

**g** удерживает голоморфность при отклонении **`Arg(⟨z⟩/z)`**; шаг **`R(Φ)`** с saturating **`Φ`** (**§3.12.5**).

| ДА | M |
|----|---|
| `Δ_disc z=0` | **`Δφ→0`**, holomorphic class |
| CR на рёбрах | **A9** |
| риманова поверхность | **`Λ×S¹`**, torus §1.7 |
| глобальная сшивка | phase sync на tick |

#### 3.9.2 Уравнение на решётке

**§3.12.5:** **`ζ`** → saturating **`Φ ∈ ℤ_{N_ring}`** → **`R(Φ)`** → leapfrog **`Z⁺+Z⁻=2Z+⌊𝒩⌋`**.

| член | ДА | M |
|------|----|---|
| **`Arg(⟨z⟩/z)`** | defect holomorphy | **`ζ` int** §3.12.5 |
| saturating kick | метрика у полюса | **`Φ_sat`**, **`K_P`** |
| unitary step | U(1) | **`R(Φ)`** |

При **`φ→0`**: **`z≈⟨z⟩`**; нелинейный **g** — конечная коррекция дефекта.

### 3.10 Спин SU(2)

#### 3.10.1 U(1)-only недостаточен

| | U(1) scalar **`z∈ℂ`** | фермионы (T) |
|--|----------------------|--------------|
| **`2π`** | **`z → z`** | **`ψ → −ψ`** |
| полный оборот | **360°** | **720°** (spin **½**) |

Без SU(2) нет Паули → condensate, нет устойчивой matter.

#### 3.10.2 Спинорное состояние

```
z(x,t) = ( z₁(x,t) , z₂(x,t) )ᵀ ∈ ℂ²
|z|² = z†z = |z₁|² + |z₂|²
```

Поле на **`ℂ²`**, не одна фаза на **`S¹`**.

#### 3.10.3 Дискретная SU(2)-эволюция

U(1)-подгруппа:

```
z' = z · exp(iΦ) , Φ ∈ ℝ
```

SU(2) (предел T, §4):

```
z'(x) = U(x,t) · z(x) , U ∈ SU(2)
U = exp( i · Θ_a · σ_a / 2 )
```

Дискретная экспонента (**§3.12.5**):

```
ω = exp(i · 2π / N_ring) , N_ring = 512 (§3.12.6)
Φ ∈ Z_{N_ring}
R(Φ) : (U,V) ↦ ( U·c_Φ − V·s_Φ , U·s_Φ + V·c_Φ ) (mod N)
δZ(Φ) = R(Φ) − Z
```

| режим | M | предел T |
|-------|---|----------|
| шаг **g** | **`R(Φ)`** на обе компоненты | **`exp(i·Φ·σ_z/2)`** |
| SU(2) mix | **`U(n,φ)`** | **`exp(i·φ·n·σ/2)`** |
| spin-½ | **`R(N/2) → −z`** | **2π→−1**, **4π→+1** |

**Следствие:** **`U(2π)=−𝟙`**, **`U(4π)=+𝟙`** на планкон **`hV`**.

#### 3.10.4 Паули и K_P

Два вихря с одинаковой спинорной ориентацией не делят один **`v_p`**:

```
z_A ∥ z_B ⇒ z_A + z_B → 0
```

**`K_P`** → отталкивание при **`d ≤ l_P`** (Pauli pressure на решётке).

#### 3.12.5 Projected collision

**`Z = U + iV ∈ ℤ_N[i]`**, **`N_ring = 512`**, **`2π_disc = N_ring`**.

\[
\omega = e^{i\cdot 2\pi/N_{\mathrm{ring}}},\qquad
R(\Phi) = \omega^{\Phi}
\]

Holonomy (без `atan2`):

\[
\zeta_{\mathrm{real}} = \left\lfloor \frac{\langle U\rangle U + \langle V\rangle V}{2^{F}} \right\rfloor,\quad
\zeta_{\mathrm{imag}} = \left\lfloor \frac{\langle V\rangle U - \langle U\rangle V}{2^{F}} \right\rfloor
\]

Saturating kick:

\[
\Phi_{\mathrm{kick}} = \left\lfloor \frac{K_P\,\zeta_{\mathrm{imag}}}{\zeta_{\mathrm{real}} + |Z|^2 + K_P} \right\rfloor \in \mathbb{Z}_{N}
\]

+ Heisenberg floor **`|Φ| ≥ Δφ_disc`**. **`⌊𝒩⌋ = R(Φ)−Z`** на обеих компонентах.

Leapfrog:

\[
Z(x,t+\Delta t) + Z(x,t-\Delta t) = 2Z(x,t) + \lfloor \mathcal{N} \rfloor \pmod N
\]

#### 3.12.6b M-native coordinates **(dh, dt)** — обобщённые координаты

**Книга:** спуск gl. descent §«Дискретизация фазы» + §«Обобщённые координаты» + §«Локальный обратимый автомат» (не отдельная гл.).

**Синонимы (уже в модели):** **`dh := hL := dl`**, **`dt := hT`**. В коде natural: **`dh = dt = 1`** (§1.1 · §3.12.0). Это не новая решётка — **словарь M**, в котором закон `g` пишется без радиан и без `ln 2` в ядре.

**Конфигурация** (один узел FCC + внутренний регистр):

```
x ∈ Λ          — позиция, счёт в hops dh
t ∈ ℤ          — дискретное время, счёт в dt
Z ∈ ℤ_N[i]     — N = 2^{⌊B_hV⌋}, N = 512
φ_disc ∈ ℤ_N   — дискретная фаза на кольце (1 шаг = δφ_ring); мультипл. ω^{φ_disc}
k_φ ∈ ℤ_{N_φ}  — сектор, N_φ = 13 (CL-6; CL-O4)
Φ ∈ ℤ_N        — kick за такт (R(Φ)=ω^Φ); ≠ φ_disc
b ∈ {0,1}      — занятость hV
```

**`(dh, dt)` — как обобщённые координаты:** пространство и время **не** ℝ³×ℝ, а **счётчики** приращений; «скорость» и «импульс» — **отношения** клеточных квантов **`s₀`**:

| M-native | в **(dh, dt)** | T/SI (мост) |
|----------|----------------|-------------|
| **`s₀`** | единица действия на `(hV, 1\,dt)` | `ℏ/2` |
| **`p₀`** | `s₀/dh` | `ℏ/(2·hL)` |
| **`E₀`** | `s₀/dt` | `ℏ/(2·hT)` |
| **`L₀`** | `s₀` | `ℏ/2` |
| **`c₀`** | `dh/dt` | `hL/hT` |
| **`g_M`** | `dh/(2·dt²)` | `c₀/(2·hT)` |
| **`F₀`** | `p₀/dt = s₀/(dh·dt)` | `m_arg·g_M` |
| **`ν₀`** | `1/dt` | `1/hT` |

Одна ступень Ландау **`s₀`** → вся механическая лестница — **арифметика (dh, dt)**, не три независимых knob (§0.8 · §5.2).

**Фаза за один `dt`:** полный цикл кольца **`N_ring`** тиков (§5.2.3 · §7.1):

```
1 dt  ⟺  оборот ℤ_N     (N_ring = 512)
δφ_ring = 1 tick        ⟺  приращение 1 mod N
Δφ_disc = 41 ticks      ⟺  Heisenberg-floor (round(N·Δφ_min/(2π)), Δφ_min=½)
```

**Без π в ядре:**

```
r = Δφ_disc / N_ring     (41/512; T: ≈ 1/(4π))
pauli_kick = N_ring/2 ticks   (256; T: π rad)
```

**Информационный бюджет** — в битах native, не `2π/ln 2`:

```
B_hV = log₂(N_ring) + ε_B ,   ε_B = {B_hV} ≈ 0.065 bit
N_hier = ⌊B_hV⌋ − 1 = 8      (бит занятости b вне иерархии; §8.4.1-A)
```

**`ε_B` = тот же класс остатка**, что `{B_hV}`: не «дыра», а **хвост при записи ёмкости в двоичных координатах** (§3.9.6 · CR).

**CR-потолки** (§3.9.6) в **(dh, dt)** при `c₀=dh/dt=1`, `ν_CA=κ_link·dh²/dt`:

```
E_CR,seed = ν_CA · ε_B²
E_CR,stab = ν_CA · (1 + ε_B)
|ΔE_CR| ≤ ε_B · E_CR
```

**Где π появляется:** только в **мосте M→T** (колонка справа): `k=2π/λ`, `ω=2π/hT`, Bekenstein `2π/ln2`, `⌈4π⌉→13`. На M закон — **congruence ladder** CL-1…CL-8 на **`ℤ_N`** и скачки **`dh`** по **`N₁₂`**.

#### 3.12.6c Внутренние координаты hV **(k_φ, φ_f, μ)** — CL-O4 (частично закрыто)

**Нотация:** **`φ_disc`** — дискретная фаза на **`ℤ_{N_ring}`**; **`ω=e^{i·2π/N}`** — генератор (**`ω^{φ_disc}`** на $S^1$); **`Φ`** — kick за такт (**`R(Φ)=ω^Φ`**), не регистр фазы.

**Не** замена **(dh, dt)** и **не** мультипликативная факторизация **`2^9 × 13`** (13 не делит 512).  
Естественная запись — **аддитивная фибрация** кольца по Heisenberg-кванту:

\[
\varphi_{\mathrm{disc}} \equiv k_\phi\cdot\Delta\varphi_{\mathrm{disc}} + \varphi_{\mathrm{f}} \pmod{N_{\mathrm{ring}}}
\]

| коорд | множество | смысл |
|-------|-----------|--------|
| **k_φ** | **`ℤ_{N_\varphi}`**, **`N_\varphi=13`** | сектор / «грань» emergent **`Ω`**, **`N_{12}+1`** |
| **φ_f** | **`ℤ_{\Delta\varphi_{\mathrm{disc}}}`**, **`Δφ_disc=41`** | тонкая фаза внутри сектора |
| **μ** | **`ℤ_{2^{B_{\mathrm{amp}}}}`**, **`B_amp=6`** | амплитуда на **`Q(2^{-6})`** (`frac_bits`) |

**Каноническая пара `(k_φ, φ_f)`** для каждого **`φ_disc ∈ ℤ_{512}`**: минимальный **`k_φ`** при **`0 ≤ φ_f < 41`**. Биекция **`(k_φ,φ_f) ↔ φ_disc`** (verify **`Internal_phase_coords`**).

**Секция вакуума (код):** **`φ_f=0`**, **`φ_disc = k_φ·41`** — `heisenberg_phase_tick(phase_class)`; это **вложение** **`ℤ_{13} → ℤ_{512}`**, не вся фаза.

**Наивная карта** **`ℤ_{13}×ℤ_{41} → ℤ_{512}`** даёт **21** коллизии — ровно

\[
N_{\mathrm{ring}} = N_\varphi\cdot\Delta\varphi_{\mathrm{disc}} - (N_\varphi + N_{\mathrm{hier}})
= 13\cdot 41 - 21,\quad N_{\mathrm{hier}}=8.
\]

**Шов (seam):** **`k_φ=0, φ_f<21`** склеивается с **`k_φ=12, φ_f≥21`**; **`21 = N_φ + N_hier`** — не случайный остаток, а связь фазовой ёмкости с иерархией занятости (§8.4.1-A).

**Полный регистр клетки** (один **`hV`**, спинор **`ℂ²`**):

```
Z_j = U_j + iV_j ∈ ℤ_{N_ring}[i]   (j=1,2)
⇔ (μ_j, k_{φ,j}, φ_{f,j})  или  (μ_j, φ_{disc,j})
```

**SU(2):** относительная фаза **`φ_{disc,1} − φ_{disc,2}`**; вакуум **`k_{φ,1}=k_{φ,2}`**, **`φ_{f,1}=φ_{f,2}=0`**.

**Словарь:**

| объект | native |
|--------|--------|
| `phase_class` (код) | **k_φ** |
| дискретная фаза кольца | **φ_disc** (= **k_φ·41+φ_f**) |
| kick за такт | **Φ**, **`R(Φ)=ω^Φ`** |
| **`{B_hV}`** | битовый хвост **`ε_B`**; **≠** seam **21** шагов |

**CL-O4 остаётся открытым:** полярная декомпозиция **`ℤ_{512}[i]`** vs **(μ, k_φ, φ_f)** на обеих компонентах; орбиты **`g`** на шве; связь **`φ_disc`** с kick **`Φ`** без float `atan2`.
