## §1. Дискретное пространство-время (Planck lattice)

```
Λ = FCC ⊂ ℝ³     (канон пространства (3+1), §1.6)
  + срез {111} = гекс   (чистый (2+1) / dogfood, §1.4 · §1.6.4)
t ∈ ℤ
dl = hL = l_P    — фиксированный шаг пространства (меньше не влезает)
hT = t_P/√2      — истинный M-тик (§1.6.2 · §7.1); t_P = l_P/c — учебниковый
dV = v_hV = l_P³/√2  — объём на узел FCC
```

**Две скорости (не одна «c=1»):**

| | символ | СИ | natural (sim) |
|---|--------|-----|----------------|
| **тактовая CA** | `c₀` | `l_P/hT` = **√2·c** ≈ 4.24×10⁸ m/s | `c₀ = dl/hT = 1` |
| **свет в вакууме (T)** | `c` | **299 792 458 m/s** (CODATA) | `c = κ·c₀`, κ=1/√2 (FCC 1-tick) |

**Сшивка (не костыль):** учебниковый `t_P=l_P/c` предполагает `c₀=c`. На каноне FCC 1-tick **`κ = 1/√2`** (§1.6.2) → **`hT = t_P/√2`**, **`c₀ = √2·c`**, macro **`c = κ·c₀`**.

**Natural units** в коде — `dl=hT=1`; размерный конус на M — **`Δx=l_P`**, **`Δt=hT`**, **`c₀=l_P/hT`** (не macro `c` в одном тике).

### 1.4 Континуум-гипотеза → **нет** (на M)

**Учебниковый** `t_P = l_P/c` — не «ошибка измерения», а **определение в continuum-рамке**:

- одна **`c`** на всех масштабах;
- смысл предела **`hL → 0`**, **`hT → 0`**;
- гладкое `(x,t)` как первичное.

**Как только** канон FCC + **`κ = 1/√2`** (§1.6.2) + CODATA **`c`** заставляют **`hT = t_P/√2`** и **`c₀ = √2·c`**, continuum-упаковка **не описывает M**:

| continuum-рамка | M |
|-----------------|---|
| один тик `t_P` | **`hT = t_P/√2`** |
| link-speed = `c` | **`c₀ = √2·c`** |
| macro `c` = link-speed | **`c = κ·c₀`** (readout) |
| предел `hL→0` | **нет** — `dl = l_P` const |

**Ответ на континуум-гипотезу (фундаментальный уровень):** **нет**.  
M — **решётка + локальный `g`**. Непрерывность, диффуры, «плавное» время — **T** (coarse, DFT, статистика на **фиксированной** сетке), не предел сетки.

**Не путать:** T **может** выглядеть континуумно — это **эффективная** теория наблюдателя; это **не** «M → continuum при `dl→0`».

**Ниже `dl` нет смысла и нет доступа:** решётка не сжимается; «внутри пикселя» меньше планковской длины **не входит** — это минимальный квант пространства M.

**Каузальность одного тика:** информация не дальше **одной осевой** клетки.

```
N(x) = { y : |y−x| = l_P  и  light-like за hT }   — канон: |N|=12 FCC (§1.6)
```

**Муур / 2-я оболочка запрещены:** за один `hT` только равные light-like рёбра `l_P` — см. §1.3.

### 1.1 Две `c` и мост **`c = κ·c₀`**

#### `c₀` — тактовая скорость M

```
c₀ = l_P / hT = √2 · c ≈ 4.24×10⁸ m/s     (SI, M-такт)
c₀ = dl / hT = 1                            (natural, sim)
c  = κ · c₀ = c_CODATA                      (T, κ = 1/√2)
```

Один тик `hT` — не дальше **одного** light-like ребра `l_P` на каноне ε (FCC N₁₂ / гекс-срез).

#### `c` — macro T (измеряемая «скорость света в вакууме»)

**CODATA `c`** = **`κ·c₀`** при **`hT = t_P/√2`**. Не «медленнее на 30%» — **учебниковый `t_P` не равен M-тику**.

```
c_T = κ · c₀        (natural; κ — readout, не новая константа SI)
```

**Механизм (канон FCC, §1.6.2):** фотон = macro-пакет; 1-tick = кубооктаэдр; **`κ = 1/√2`** — вписанная сфера / изотропный T-фронт. На гекс-срезе — **`κ_hex = √3/2`** (§1.4.2).

```
κ_FCC = 1/√2 ≈ 0.7071     (канон 3+1)
κ_hex = √3/2 ≈ 0.8660     (срез 2+1)
```

| Слой | Скорость (natural) | Геометрия |
|------|---------------------|-----------|
| M, link | `c₀` | ε канона (FCC / гекс) |
| T (isotropic readout) | **`κ·c₀`** | вписанная сфера / окружность |
| SI macro | `c = κ·c₀` = CODATA | §7 |

κ **не fitted** — геометрия конуса.

### 1.2 «Сверхсвет» относительно T — только на масштабе `dl`

**Micro (M)** causal bound: не быстрее **`c₀`** по решётке (A1). Это потолок, не энергетический тюнинг.

**Macro (T)** наблюдает **`c_T ≈ c₀/√2`** (isotropic readout). Структура с **полным micro-конусом** `c₀` по оси для T-наблюдателя:

```
v_T ≈ (c₀ / c_T) · c_T  = √2 · c_T        (относительно macro-«света»)
```

«Сверхсвет» здесь = **быстрее macro-c**, не нарушение micro-каузальности и не `v > c₀^SI`.

**Условие доступа:** локализован в **одном `dV`** (элементарный масштаб, `dl = l_P`). Составная структура (>1 dV) **усредняется** на T → снова **`κ = 1/√2`**, macro-c.

```
размер ≈ dl ,  в одном dV   ⇒   может нести micro c₀ (ось)
размер ≫ dl ,  составная     ⇒   T видит c_T ≈ c₀/√2
```

**Честность:** это следствие геометрии M→T + §5 (элементар vs составная), не ticket для макро-FTL. Сигнал быстрее macro-c **не выходит** за micro-конус `c₀`; «быстрее c» — артефакт coarse readout.

### 1.3 Окрестность ε — световой конус

**Общее правило A1 (любая решётка):**

```
N(x) = { y : |y−x| = l_P  и  Δs² = c₀² hT² − |y−x|² ≥ 0 }
```

За один `hT` в ε входят **только равные light-like** рёбра длины **`l_P`**. Любая более длинная связь за тот же тик — **space-like**, запрещена.

Схема `g` одна (§1.6.5): меняется только `|N|` от упаковки.

**Канон (3+1):** FCC **N₁₂** (§1.6). **Срез (2+1):** гекс **N₆** (§1.4). Квадрат / SC / D2Q9 — **не M** (история кода → DEVLOG).

Тип ε → **`f_геометрия(n, ε)`** (§8.2).

### 1.4 Форма ячейки · 2D: гекс из упаковки · срез (2+1)

#### 1.4.1 Три регулярных замощения плоскости

КА требует замощения без дыр. В 2D ровно три регулярных тайла: **треугольник** (3 соседа), **квадрат** (4), **шестиугольник** (6).

| требование | что отсекает |
|------------|--------------|
| замощение плоскости | всё, кроме 3 тайлов |
| A1 + равный **`l_P`** на рёбрах | неравные связи (Moore-диагональ на квадрате) |
| наиплотнейшая изотропная упаковка центров при масштабе **`l_P`** | треуг. решётка центров → **Voronoi = гекс**, **6** равных light-like соседей |
| max дискретный остаток SO(2) | **C₆ > C₄ > C₃** → снова гекс |

**Гекс** — канон среза **(2+1)** из упаковки + изотропии (A1 · C₆). Квадрат **N** — **не носитель M**; только история кода — [DEVLOG](DEVLOG.md).

#### 1.4.2 κ и `hT` на гексе (тот же метод, что §1.1)

Micro-каузальный шар за **`R`** тиков — **правильный шестиугольник** (graph ball на треугольной решётке центров, шаг **`l_P`**).

```
вершина (circum):   R_eucl = R · l_P          →  κ_vertex = 1
плоская грань (in): R_eucl = R · l_P · √3/2   →  κ = √3/2
```

**Macro-изотропный свет** = вписанная окружность в каузальный многоугольник:

```
κ_hex = √3/2 ≈ 0.8660254038
c     = κ · c₀ = CODATA          (по построению)
c₀    = c/κ = 2c/√3 ≈ 1.154700538 · c
hT    = κ · t_P = (√3/2) · t_P
E₀    = s₀/hT = (ℏ/2)/hT = E_P/√3
κ_link = 1/|N₆| = 1/6
ν_CA (natural) = 1/6
```

| | гекс **N₆** (срез 2+1) | FCC **N₁₂** (канон 3+1) |
|--|------------------------|-------------------------|
| **κ** | **`√3/2`** | **`1/√2`** (§1.6.2) |
| **hT** | **`(√3/2)·t_P`** | **`t_P/√2`** |
| **c₀** | **`(2/√3)·c`** | **`√2·c`** |
| **κ_link** | **`1/6`** | **`1/12`** |
| поворот решётки | **60° (C₆)** | кубооктаэдр |

**CODATA `c`:** сходится на обоих — меняется только разбиение `c = κ·c₀`.

**`4π` в gate / α_fs — телесный угол сферы (emergent 3D readout), не координационное число решётки.**

```
α* − 1 = Δφ_min / (2π) = (1/2)/(2π) = 1/(4π)
α*     = 1 + 1/(4π) ≈ 1.0795774715          — то же на гексе

α_fs⁻¹ = 4π³ + π² + π ≈ 137.03630378       — то же на гексе
α_fs   ≈ 0.00729733634                     — vs CODATA ≈ 0.00729735257
```

**Запрещено:** подставлять `|N|·π³+…` (для `N=6` → `α_fs⁻¹≈199` — ломает CODATA). Коэффициент **`4`** в **`4π³`** = **`4π` (стерадиан) × π²**, не **`|N|`**.

| величина | гекс меняет? | macro |
|----------|--------------|-------|
| **`c` CODATA** | нет (`κ` переопределён) | ✅ |
| **`α_fs`, `α*`** | нет | ✅ |
| **`l_P`, `m_P`, `B_hV`, `N_ring`** | нет | ✅ |
| **`hT`, `c₀`, `E₀`, `κ_link`, `ν_CA`** | да | внутренние M; SI-мост пересчитать |
| **`f_геометрия(e)`** | да (топология узла на ε) | check §8.2, не knob |

### 1.5 Обратный ход: из физики твёрдого тела → M (второй кусок пазла)

**Метод:** не «M похож на кристалл», а **что должно быть ниже**, если классическая ФТТ — следствие укрупнения масштаба.

#### 1.5.1 Что ФТТ считает данным

1. Эквивалентные центры (атомы/ионы) на решётке Браве.  
2. Каждому — **ячейка Вигнера–Зейтца** (= Вороной).  
3. Соседи = общая грань WS; колебания решётки → фононы; электроны на периодическом фоне → Блох / зоны / зона Бриллюэна (= Вороной в **k**-пространстве).  
4. Длинноволновый предел → упругость / гидро / «сплошная среда».  
5. Плотные металлы → FCC/HCP: снова **наиплотнейшая упаковка**.

#### 1.5.2 Спуск на один масштаб вниз

Атомный кристалл **не** фундамент: атом — составной узел. Но **жест** ФТТ универсален: *где есть равные конкурирующие центры — есть Браве + Вороной + зона Бриллюэна*.

Если под атомами лежит среда из **элементарных равных носителей** масштаба `l_P` (Postulate 0 / `hV`), тот же жест **обязан** повториться:

```
ФТТ (Å):   центры = атомы     → WS → фононы matter → зоны электронов
M (l_P):   центры = hV        → WS → «фононы/моды вакуума» → моды z на Λ
```

**Два вложенных кристалла**, один геометрический словарь:

| слой | центры | ячейка | «частица» слоя | длинная волна |
|------|--------|--------|----------------|---------------|
| **M** | `hV` @ `l_P` | Вороной вакуума (2D: гекс) | pra-вихрь / мода `z` | T-гидро, light cone §1.1 |
| **T / ФТТ** | атомы @ Å | Вигнер–Зейтц вещества | фонон, электрон Блоха | упругость, термодинамика твёрдого |

#### 1.5.3 Куда выводит обратный ход

1. **Гекс/FCC не «опция сима»** — тот же селектор плотной упаковки, что в металлах, нанесённый на `hV`.  
2. **Зона Бриллюэна M** — жёсткий UV по импульсу: `|p| ≲ πħ / l_P` (порядок); continuum `p→∞` запрещён не костылём, а первой зоной вакуумного кристалла.  
3. **Материя как дефекты/конденсат** на вакуумной решётке: вакансии, дислокации, примеси в ФТТ ↔ топологические узлы `n∈ℤ`, антиматерия `n→−n`, «химия/твёрдость» как устойчивые составные узлы (§3.10, §4.9.2) — не шарики в пустоте.  
4. **Фононы вещества** не отменяют M: это коллективные моды *второго* (атомного) кристалла; под ними кипит первый.  
5. **Bloch в ФТТ** ↔ волны на периодическом `Λ`; локальный **Bloch-вектор спинора** в §3.11 — другой объект (внутренняя SU(2)-сфера), но рифма имён не случайна: периодический носитель + внутренняя сфера.

#### 1.5.4 Чего ход **не** утверждает

- Что атомная решётка = укрупнение тех же `hV` один-в-один ( commensurability Å/`l_P` — T-статистика, не тождество узлов).  
- Что фонон = фотон или = гравитон без отдельного вывода.  
- Что код (sim-gap) уже считает зоны Бриллюэна M — **model → sim** open.

**Склейка пазла:** §1.4 (упаковка → тайл M) + §1.5 (ФТТ = второй Вороной на T) = одна иерархия масштабов, не две физики.  
**Новые ступени лестницы** (Бриллюэн / умклапп / `N_pack` / вложенные `b`) — **§5.2.4**. **3D-селектор тайла** — **§1.6**.

### 1.6 Три измерения: обоснованный выбор ε = FCC + 12 NN

#### 1.6.1 Теорема выбора (3D): упаковка ∧ конус ⇒ **N₁₂ на FCC**

**Дано (из уже принятого):** замощение без дыр; единственный `l_P`; A1 — только light-like рёбра за один `hT`; изотропия вакуума (нет предпочтённой оси); КА с **одним** носителем на узел (§1.6.5); физическое пространство **3D** в Минковском **(3+1)**.

**Шаг A — решётка центров (упаковка).**  
Равные шары радиуса ~`l_P/2` → наиплотнейшая упаковка в 3D: доля **`π/(3√2)≈0.74`**. Реализации: **FCC** и **HCP** (обе 12 NN).  
Простая кубическая (6) и BCC (8) — заметно реже → отсечены упаковкой.  
Для «один `hV` = один узел Браве» предпочтителен **FCC** (HCP — 2 на примитивную ячейку).

**Шаг B — окрестность (конус, §1.3).**  
На выбранной решётке ε = **первая** координационная сфера: все рёбра длины `l_P`, `Δs²=0`.  
Следующие оболочки (`√2 l_P`, …) за один `hT` space-like — **запрещены** (тот же дух, что Мур на квадрате / 26 на SC).

**Следствие:**

```
канон (3+1):   Λ = FCC ,   N(x) = N₁₂(x) ,   |N| = 12 ,   κ_link = 1/12
```

Это **обоснованный выбор**, не GPU-вкусовщина. Канон размерности 3 — только FCC N₁₂; гекс — срез (§1.4 · §1.6).

**Voronoi FCC** — ромбический додекаэдр (Вигнер–Зейтц). Мягкий хвост: FCC vs HCP как укладка слоёв — не меняет `|N|=12` и конус.

#### 1.6.2 Кванты на FCC

```
κ_link = 1/|N₁₂| = 1/12
v_hV   = l_P³ / √2          (объём на узел FCC при NN = l_P; не l_P³ куба)
```

**κ (macro-свет):** тот же метод — вписанная сфера в каузальный многогранник.

- **1 тик:** выпуклая оболочка 12 NN = **кубооктаэдр** → inradius/circumradius = **`1/√2`** (лимитируют квадратные грани).  
- **Объём 1-tick оболочки** при ребре **`a = l_P`** (12 NN на расстоянии **`l_P`**):

```
V_cuboctahedron = (8/3)√2 · l_P³ = (16/3) · v_hV        (§8.2·geo)
v_hV            = l_P³/√2   — объём узла FCC (Вороной), не то же число, но связано жёстко
```

- **Асимптотический** graph-ball FCC (большой R) — отдельный численный leaf; локальный 1-tick уже даёт:

```
κ_FCC^(1) = 1/√2     ⇒     hT = t_P/√2 ,   c₀ = √2·c
```

**Смысл для пазла:** SI-мост `κ=1/√2` (§7) = геометрия **1-tick** каузальной оболочки FCC (кубооктаэдр), не «случайность квадрата». Срез **(2+1)+гекс** честно несёт свой `κ=√3/2` (§1.4 · §1.6.4).

| | 2D гекс (срез/чистый 2D) | 3D SC (отсечён) | **3D FCC (канон)** |
|--|-------------------------|-----------------|---------------------|
| κ (вписанная) | `√3/2` | `1/√3` | **`1/√2` (1-tick)** |
| κ_link | `1/6` | `1/6` | **`1/12`** |
| c₀/c | `2/√3≈1.15` | `√3≈1.73` | **`√2≈1.41`** |

**α_fs, α\*** — от `4π` / `Δφ_min`, не от `|N|` (§1.4.3).

#### 1.6.4 Связка размерностей: (3+1) ↔ (2+1) и FCC ↔ гекс

**Уточнение (Минковский, не «решётка L⁴»):**

```
4D_Mink = 3D_space + t     — физический канон M
3D_Mink = 2D_space + t     — честный срез / sim-вселенная
```

Оба с дискретным временем **`hT`** (Postulate 0). Разница — только в **пространственном** сечении.

**Пространственный кусок** тот же, что в кристаллографии:

| Минковский слой | пространство | тайл / NN | κ (1-tick light) |
|-----------------|--------------|-----------|------------------|
| **(3+1)** | FCC @ `l_P` | 12 NN | **`1/√2`** → якорь CODATA `c` |
| **(2+1)** | слой `{111}` FCC = гекс | 6 NN в плоскости (+ bulk, если не отрезан) | изолированно **`√3/2`** |

**Погружение:** `(2+1) ↪ (3+1)` — взять мировые линии / поле `z` только на одной пространственной плоскости плотной упаковки + общее дискретное `t`.  
**Не** ортогональная проекция всего 3D сразу на 2D (слои ABC слипнутся).

**Следствия:**

1. Симулятор **(2+1)+гекс** — Minkowski-срез физического **(3+1)+FCC**, не другой закон природы.  
2. SI-мост **`κ=1/√2`**, **`c₀=√2·c`** якорить на **(3+1)**; в чистом **(2+1)** без bulk свет/поток не уходит «вверх-вниз» → другой эффективный `κ`.  
3. Время одно и то же: **`hT`**, leapfrog, Гейзенберг — наследуются срезом; меняется только пространственная звезда ε.

#### 1.6.5 Инвариант: один КА, не «гекс на плоскости / FCC в объёме»

**Запрещено:** закон, который узнаёт «я сейчас в 2D или в 3D?» и меняет вид `g` (сегодня гекс, завтра FCC). Наблюдатель внутри M не переключает бренд автомата.

**Инвариант — схема `g`, не конкретный тайл:**

```
N(x) = { y : |y−x| = l_P , light-like за один hT }     — равные каузальные рёбра
κ_link = 1 / |N(x)|
ζ = (Σ_{y∈N(x)} z(y)) · z(x)*
Φ = Φ(K_P, ζ, ρ, …)       — те же скаляры
z ← leapfrog + R(Φ)         — тот же tick
```

**Что зависит от размерности пространства** — только **геометрия упаковки центров** (сколько равных NN влезает):

| пространство | упаковка | `|N|` | имя тайла |
|--------------|----------|-------|-----------|
| чисто 2D (нет 3-й оси) | плотнейшая | 6 | гекс |
| 3D | плотнейшая Браве | 12 | FCC |
| срез `(2+1)↪(3+1)` | слой `{111}` | 6 в плоскости + связь с bulk | тот же `g`, урезанный носитель |

Агент на срезе **не** «переехал с гекса на FCC». Он всегда на **том же** локальном правиле; меняется только множество соседей, которое **уже задано** решёткой вакуума. В полном `(3+1)` соседей 12; на изолированной плоскости без bulk — 6; на погружённом слое — 6 плюс потоки «вверх-вниз».

**κ и `c`:** не свойства «настроения КА», а следствия формы каузальной звезды при данном `|N|` / многограннике. Якорь CODATA — у физической `(3+1)+FCC`; `(2+1)`-sim честно считает свой срез.

**Код:** `stencil` / `|N|` — параметр геометрии носителя; тело `projected_collision` / gate — одно. Hard-code «только N» = sim-gap, не онтология.
