# §0 · Основания M

## §0. Основания M
**Постулат 0.1 — заменён теоремой 0.1 (§0 · ниже).** См. **Теорема 0.1** — дискретность **`Λ`**, шаг **`hL`**, тик **`hT`** из **A1–A3, A7, A10, A13, A16** + §1.6 + §3.12.6, **не** отдельный «CA postulate».
### Теорема 0.1 — Дискретность и минимальный **`hV`** (не Postulate)
**Утверждение:** допустимый **`g`** не живёт на **`x ∈ ℝ³`**. Существует **счётный** FCC-носитель **`Λ`**, минимальная ячейка **`hV`**, шаг **`hL`**, тик **`hT`**; **«ниже `dl`**» **не состояние M** — не аксиома, а **запрет под-решётки**.
| лемма | из | следствие |
|-------|-----|-----------|
| **0.1a** | **A3 · A13 · §3.12 `Z_N[i]`** | алфавит **конечен** на сайте → пространство состояний **счётно**; эволюция — перестановка конфигураций, не континуум полей |
| **0.1b** | **A1 · A2 · §1.6** | каузальный граф **равных** light-like рёбер → **`Λ = FCC`**, **`N₁₂`**; длина ребра = **`hL`** |
| **0.1c** | **A10 · A11** | заряд **`n ∈ ℤ`** на **`∂(hV)`**; устойчивый soliton **не** «пол-`hV`» — ячейка **топологически атомна** |
| **0.1d** | **A7 · A5 · §3.12.6** | **`B_hV = 2π/ln2`**, **`N_ring`**, **`Δφ_min=½`**, **`z_min>0`** → амплитудная/фазовая сетка с **дном**; дробление **`hV`** = новый регистр, **не** тот же **`g`** |
| **0.1e** | **A16 · §5.2.1** | **`s₀ = ℏ/2`**, **`p₀ = ℏ/(2hL)`** — насыщение неопределённости **на одном **`hV`**** фиксирует **`hL`** при данном **`ℏ`** (не **`c`**) |
**Следствие:** **«дискретность»** = следствие **информации + каузальности + топологии + потолка плотности**, не отдельный postulate «решётка exists». **Шкала **`hL`**** и имя **`ℓ_P`** — §7.3–7.4; **`√(ℏG/c³)`** — check.
**Сводка 0.2 — SI после идентификации (не вход в `g`; см. §7.3–7.4).** Когда **`ℓ_P := hL`**, **`a = hL`**, **`κ`** из hull:
```
ℓ_P := hL — теорема §7.4, не Postulate 0
hT = t_P/√2 — M-тик; t_P = ℓ_P/c — учебниковая метка (c = check)
c₀ = hL/hT = √2·c — тактовая скорость M
c = κ·c₀ , κ = 1/√2 — macro CODATA — слой согласованности
dV = v_hV = ℓ_P³/√2 — Voronoy FCC (§8.2·geo·voronoi)
√(ℏG/c³) — проверка с CODATA, не определение hL
```
**Постулат 0.3 — Состояние и эволюция.**
```
z(x,t) ∈ Z_N[i] на v_p — целочисленный спинорный инвариант (§3.12)
Ψ^{t+1} = g(Ψ^t) — локально по ε FCC: FCC N₁₂ (§1.6); гекс = срез {111}
```
Один M-тик = один **`hT`**. Закон **`g`** — **локальный**, **2-го порядка** (§3.12). Float на M — только декодирование для T для T; не альтернативная физика ячейки.
**Следствие 0.4 — Континуум на M.** **Нет** (§1.4). Непрерывные поля, диффуры, «плавное» время — **T** (макроописание на **фиксированной** решётке), не предел **`hL → 0`**.
**Следствие 0.5 — Планковский пол амплитуды (A5 · §3.12.6).** На **`hV`** нет «устремления в ноль» — ни как knob, ни как предел:
```
z_min = 2^{−B_amp} = 1 / Q(frac_bits) — одна амплитудная кванта ячейки
|z(x)| ≥ z_min на M (Z_N[i]); |z|² = 0 только c=0 — excluded §0.10
vacuum_amplitude = z_min — derived, не fitted
```
**A5:** абсолютный ноль **недостижим** ⇒ **`ρ_field > 0`** на вакууме; **Heisenberg **`Δφ_min=½`**** + **`N_ring`** (§3.12.6) — фазовая сетка тоже с **дном**. Некуда «сжать» вселенную ниже **`hV`**-бюджета.
**Следствие 0.6 — Пена M ≠ наблюдаемая Вселенная (время).** Планковское **кипение (A5)** — substrate: **`g`** тикает для всех **`t ∈ ℤ`**, **нет** M heat death (§2.3). Это **не** то же, что космологическое «начало» **наблюдаемой** Вселенной (генезис UI, пузырь ~13.8 Gyr) — там **начало есть**, но **не** «первый тик M». Карточка двух «времён»: **[`META.md` §3.0](../META.md#30-два-времени-пена-m-vs-наблюдаемая-вселенная)**.
### Следствие 0.7 — Закон **`g`** из A1–A16 (не отдельный ansatz)
**Утверждение:** допустимый локальный **`g`** — замыкание §3.12: **leapfrog 2-го порядка** + **projected collision** на **`Z_N[i]`**. Не «postulate CA rule», а **замыкание** таблицы §3.2.
| лемма | из | следствие |

| **0.7a** | **A1 · A2 · §1.6** | stencil **FCC N₁₂**; **`g(x)`** только из ε |
| **0.7b** | **A3 · A4 · A13** | **`Σ|z|²`** invariant; нелинейность только **`R(Φ)=ω^Φ`**; **2-й порядок** **`Z⁺+Z⁻=2Z+⌊𝒩⌋`** |
| **0.7c** | **A5 · A7 · A8 · A9 · A11** | saturating **Φ**: **`K_P·ζ/(ζ_real+\|Z\|²+K_P)`**; holonomy **ζ**, не `atan2` |

**Следствие:** **A1–A16** — система ограничений, из которой собран **g** (§3.12).
### Следствие 0.8 — Механика (Landau-лестница) из Thm 0.1 + **`g`**
**Утверждение:** на **`hV`** нет отдельных postulate для **`p`**, **`L`**, **`F`**, **`E`**. Одна **Landau-ступень** **`s₀`**, остальное — **арифметика** **`(hL, hT)`** + реестр импульса §3.12.
| лемма | из | следствие |
|-------|-----|-----------|
| **0.8a** | **A5 · §3.7 · §5.0.2** | **`Δφ_min=½`** ⇒ **`s₀=ℏ/2`** — минимальное **действие** Arg-события |
| **0.8b** | **Thm 0.1 · §7.4** | **`p₀=s₀/hL=ℏ/(2hL)`**, **`E₀=s₀/hT`** — без отдельного knob импульса/энергии |
| **0.8c** | **§5.2.1 · Thm 5.1** | **`L₀=p₀·hL=s₀`**, **`g_M=c₀/(2hT)`**, **`F₀=p₀/hT=m_arg·g_M`** — **F=mg** на **`hV`** |
| **0.8d** | **A3 · A13 · §3.12 `⌊𝒩⌋`** | перенос **`p,L,F`** — **целые кратности** **`p₀,L₀,F₀`** (ledger), не float **`∫ Im(z*∇z)`** |
| **0.8e** | **§5.2.2** | **`E=n_E·E₀`**, **`E₀=p₀·c₀=F₀·hL=L₀/hT`** — одна лестница, не три аксиомы |
**Следствие:** continuum **`p,L,F`** и Madelung **`j`** — **макроописание T** (§4.3); на M — **Planck-арифметика** той же **`s₀`**, что **`⌊𝒩⌋`**.
### Следствие 0.9 — Полное квантование: **нет волны на M**, есть **кванты возбуждения**
**Утверждение:** на M **нет** фундаментального поля «**`A·sin(kx−ωt)`**». Любое возбуждение — **целочисленная занятость** дискретной моды: **`n_k ∈ ℤ`** (фонон/фотон/пакет **`n_E·E₀`**). «Волна», «звук», «интерференция» — **макроописание T** суперпозиции **многих** квантов + binomial **`Φ`**, не ontologia M.
| лемма | из | следствие |
|-------|-----|-----------|
| **0.9a** | **A3 · §3.12 · §5.2.2** | передача энергии только **`n_E·E₀`**, **`n_E∈ℤ`** (реестр импульса) |
| **0.9b** | **Thm 0.1 · §5.2.4** | период **`Λ`** ⇒ **1-я зона BZ**; **`p = n·p₀ + ℏk`**, **`k`** дискретен; **umklapp** |
| **0.9c** | **§5.2.4 · §5.2.6 · §1.5** | **фонон **`n_k`**, **`ω(k)=v_a|k|`**, **`v_a=2c₀`**, **`k_{\max}=\pi/hL`** — параметры от FCC WS |
| **0.9d** | **§4.9 · §8.2** | **свет** = **`n=0`**, **`E=n_E·E₀`**, **`ν=n_E/hT`**; не отдельная «волновая» сущность |
| **0.9e** | **§5.3.2 · §4.1** | macro **`v_s`**, Madelung **`j`**, **`|Φ|²`** — **T**; на M — **ledger + mod **`E₀`** |
**Следствие:** **полное квантование** = механика (**Thm 5.1**) **+** спектр мод на **`Λ`**. Фонон вещества (ФТТ) — **второй** кристалл над M; фонон/мода вакуума — **первый**. **Не смешивать** каналы без вывода (§1.5.4).
