## §0. Основания M

**Постулат 0.1 — Дискретность.** Фундаментальный уровень — **клеточный автомат** на фиксированных шагах **`(hL, hT)`**. Под **`dl = hL`** в M нет структуры (§1, §5).

**Определение 0.2 — Шаги и скорости** (Planck-идентификация, §7.1 · канон носителя §1.6):

```
hL = l_P                          — шаг решётки
hT = t_P/√2                       — M-тик; из 1-tick FCC (кубооктаэдр), §1.6.2; t_P = l_P/c — учебниковая метка, ≠ hT
c₀ = hL/hT = √2·c                 — тактовая скорость M
c  = κ·c₀ ,  κ = 1/√2             — macro CODATA (T-readout на каноне FCC)
dV = v_hV = l_P³/√2               — объём на узел FCC при NN = l_P (§1.6.2)
```

**Постулат 0.3 — Состояние и эволюция.**

```
z(x,t) ∈ Z_N[i]  на v_p           — целочисленный спинорный инвариант (§3.12)
Ψ^{t+1} = g(Ψ^t)                  — локально по ε канона: FCC N₁₂ (§1.6); гекс = срез {111}
```

Один M-тик = один **`hT`**. Закон **`g`** — **локальный**, **2-го порядка** (§3.12). Float на M — только decode/readout для T; не альтернативная физика ячейки.

**Следствие 0.4 — Континуум на M.** **Нет** (§1.4). Непрерывные поля, диффуры, «плавное» время — **T** (readout на **фиксированной** решётке), не предел **`hL → 0`**.

**Следствие 0.5 — Планковский пол амплитуды (A5 · §3.12.6).** На **`hV`** нет «устремления в ноль» — ни как knob, ни как предел:

```
z_min = 2^{−B_amp} = 1 / Q(frac_bits)     — одна амплитудная кванта кирпича
|z(x)| ≥ z_min   на M (Z_N[i]);  |z|² = 0  только c=0 — excluded §10.2
vacuum_amplitude = z_min                    — derived, не fitted
```

**A5:** абсолютный ноль **недостижим** ⇒ **`ρ_field > 0`** на вакууме; **Heisenberg **`Δφ_min=½`**** + **`N_ring`** (§3.12.6) — фазовая сетка тоже с дном. Некуда «сжать» вселенную ниже **`hV`**-бюджета.
