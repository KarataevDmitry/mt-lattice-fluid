# §4 · M → T (macro)

## §4. M → T (macro; без предела hL→0)
### 4.0 Зачем переход **принципиален** (не технический coarse)
**`dl = l_P` и `dV = (dl)³` известны** как определения из `ℏ, G, c` (§7) — но **засечь их прибором нельзя**: слишком маленький размер и объём. Это не «ещё не построили микроскоп» — **принципиальный** предел доступа.
**Красивый выход:** механика **как предельный переход `c → ∞`**, только **наоборот** — и **без** continuum на M (§1.4):
| Классика | Наша модель |
|----------|-------------|
| micro relativistic, `c` finite | **M** — дискретный, `c₀ = dl/hT` fixed |
| предел `c → ∞` / **`hL → 0`** | **нет** — continuum-гипотеза **отвергнута** на M |
| остаётся **macro** (Newton) | остаётся **T** — наблюдаемый мир (может *выглядеть* гладким) |
| transition: убрать релativistic corrections | transition: **M → T** (усреднение + дискретный анализ) |
Макромир **остаётся** единственным слоем, к которому есть доступ. Значит, из M **обязан** следовать T — не опция, а **структура познания и модели**.
```
M — КА на решётке (никогда не «увидим» напрямую)
 ↓ binomial macro readout (§4.1); DFT — §4.3
T — волны, c, mass, SM-наблюдаемые («наш мир»)
```
**Проверка модели** — только на **T** (T1/T2, dispersion, SM). **M** верифицируется косвенно: если T-инварианты сходятся, M-каркас не refuted.
### 4.0.1 M→T: якорь — **известный T** (электрон)

**Смысл:** берёшь **T-объект с известными параметрами** — электрон, `m_e`, `e` — и спрашиваешь: **из чего он на M?**
**Сдвиг:** кварки — **не** фундаментальный предел. Предел — **`v_p = dV = (dl)³`**.
```
частица(ы) в v_p — планкон, один dV (§5)
 ↓ комбинации
кварки, пре-резонансы
 ↓
электрон, протон, … ← T: уже validated снаружи
```
**Проверка M→T** = комбинации `v_p` + `g` **дают** известный электрон (или **любой** другой точный SM-объект) **без** новой подгонки. Не сходится → refute.
Coarse / T1 / dispersion — **механизм** слоя T. **Электрон** — **конкретный** якорь «мы смотрели не туда: не кварк, а `v_p`».
### 4.1 Оператор макро-усреднения (ядро фильтрации)
**Не** простое арифметическое среднее по блокам: **резкие границы** macro-блоков порождают **ложные отражения** волн на T-слое.
#### 4.1.0 Вывод ядра **(1-2-1)** — ответ физики конуса (A1)
**Вопрос:** почему **`[1,2,1]/4`**, а не произвольный blur? Вывести из **светового конуса**, не у вкуса фильтра.
**Посылки** (уже заданы — не новые knobs):
| # | Физика | Утверждение |
|---|--------|-------|
| **C0** | Прибор не читает одну `v_p` | §0.4 |
| **C1** | Readout линеен по `z` до `|Φ|²` | §2.1 |
| **C2** | `W≥0`, `ΣW=1` | мера вклада |
| **C3** | За один `hT` только **light-like** рёбра длины `l_P` — **нет rest-ребра** «остаться на месте» как отдельного A1-хода | §1.3 · A1 |
| **C4** | Вес сайта в soft-readout ∝ **число null-путей**, дошедших до события прибора (Green конуса) | каузальная апертура §1.1–§1.3 |
##### Зачем **два** тика (не «два полушага вкуса»)
При **чистом** A1 (только light-like):
- **Глубина 1:** из `x` за один `hT` достижимы **только** соседи `N(x)`. Центр **не** в оболочке. Среднее по 1-tick конусу = среднее по звезде ε — это **M-mixing** (`κ_link`), не T-blur с весом в центре.
- **Глубина 2:** есть пути **туда–обратно** (вышел на соседа и вернулся) ⇒ центр снова в support; пути длины 2 на цепи `ℤ` считаются биномом Паскаля:
```
# путей длины 2: −2:1 , 0:2 , +2:1 → после сдвига/нормировки к support ±1
# эквивалент: [1, 1]/2 ∗ [1, 1]/2 = [1, 2, 1]/4
```
**Вывод:** множитель «два» — **минимальная чётная глубина**, при которой Green конуса (C3+C4) смешивает центр с соседями. Не произвольная композиция «неразличимости».
Атом `[1,1]/2` здесь = один light-like шаг вдоль оси (два исхода: ±), не отдельный метафизический постулат.
##### Сепарабельность — когда да / когда нет
| Носитель | Сепарабельное `(1-2-1)⊗…` | Что говорит физика |
|----------|---------------------------|--------------------|
| **n4 / кубический product-срез** (ортогональные оси) | **да** | null-шаги по осям независимы → `W = w₁⊗w₁` |
| **гекс N₆** (срез {111}) | **нет** как закон ε | C₆, не product `ℤ²`; нативный вес — счёт путей на треугольной решётке центров |
| **FCC N₁₂** | **нет** | кубооктаэдр; нативный soft-readout = **мультиномиал / Green на графе N₁₂**, не `(1-2-1)^{⊗3}` |
**κ и macro-c** (§1.1 · §1.6.2) уже выводятся из **геометрии** каузального многогранника (вписанная сфера) — **без** выбора биномного ядра. Конус → `κ`; бином → амплитудный soft-фильтр на **допустимом** срезе.
##### Sim vs пространство (3+1)
```
Φ_slice = (1-2-1)^{⊗2·R} z — ортогональный срез (§1.4)
Φ_FCC = G_{FCC}^{(2R)} ∗ z — открыто: path-count Green глубины 2R на N₁₂
```
`ν_CA = κ_link · c₀ · l_P` с **`κ_link = 1/|N|`** (§4.1.2 · §1.4.2): на N₄ → `¼`, на гексе → `⅙`, на FCC → `1/12`. Это согласовано с **координацией конуса**, не требует сепарабельного 1-2-1 на FCC.

#### 4.1.0-T · Теорема **T-CR** — continuum как вынужденный T-readout
**Утверждение.** Continuum **не** аксиома M (`hL↛0`). При C0–C4 любой прибор с soft-радиусом `R≥1` (в `ℓ_P`) видит поле, неотличимое от континуального на шкалах `λ≫σ_R`, с контролируемой ошибкой. `σ_R` — ширина Green, не предел решётки.
**Посылки:** C0–C4 (§4.1.0) · A1 · фиксированный `ℓ_P`.
##### Доказательство — цепочка
```
C0–C4 ⇒ soft Φ = W∗z, W≥0, ΣW=1, support ⊆ light-cone Green
 ⇒ (A) product-срез: W = (1-2-1)^{⊗d·R}
 или (B) FCC/hex: W = path-Green графа NN
 ⇒ высоко-k подавлены; низко-k = Gaussian/PDE до O((kσ)⁴)
 ⇒ на λ≫σ_R мир «гладкий» — без hL→0 на M
```
##### (A1) Один проход: тождество множителя
Свёртка на `ℤ` с весами `[1,2,1]/4`:
$$
(Wz)_n=\frac14 z_{n-1}+\frac12 z_n+\frac14 z_{n+1}.
$$
Фурье (`z_n=e^{ikn}`):
$$
\widehat W(k)
=\frac14 e^{-ik}+\frac12+\frac14 e^{ik}
=\frac12+\frac12\cos k
=\cos^2\frac{k}{2}.
$$
(Последнее: `cos²(θ)=(1+cos 2θ)/2` при `θ=k/2`.)
##### (A2) Дисперсия и `R` проходов
Атомная вероятностная мера на `{-1,0,+1}` с массами `(1/4,1/2,1/4)`:
$$
\mathbb{E}[X]=0,\qquad
\mathrm{Var}(X)=\mathbb{E}[X^2]=\tfrac14(1)+\tfrac14(1)=\tfrac12.
$$
`R` независимых свёрток ⇒ `Ŵ_R(k)=\widehat W(k)^R=\cos^{2R}(k/2)`, суммарная дисперсия
$$
\sigma_R^2=R\cdot\tfrac12=R/2.
$$
Гауссов continuum-прокси **с тем же вторым моментом**:
$$
G_R(k)=\exp\!\big(-\sigma_R^2 k^2/2\big)=\exp\!\big(-R k^2/4\big).
$$
##### (A3) Лемма — полный ряд (малый `k`)
Разложение `log cos` (стандартный Taylor при `|k|<π`):
$$
2\log\cos\frac{k}{2}
=- \frac{k^2}{4}-\frac{k^4}{96}-\frac{k^6}{1440}-\frac{17k^8}{322560}-\cdots
$$
(проверка: `series(2 log cos(k/2), k→0)`).
Следовательно
$$
\log\widehat W_R(k)
=R\cdot 2\log\cos\frac{k}{2}
=- \frac{R k^2}{4}-\frac{R k^4}{96}+O(R k^6),
$$
$$
\log G_R(k)=-\frac{R k^2}{4},
$$
$$
\frac{\widehat W_R(k)}{G_R(k)}
=\exp\!\Big(-\frac{R k^4}{96}+O(R k^6)\Big).
$$
При `k→0` (фиксированное `R≥1`):
$$
\frac{\widehat W_R}{G_R}-1
=- \frac{R k^4}{96}+O(k^6)
=O(k^4)=O\big((k\sigma_R)^4\big),
$$
поскольку `σ_R²=R/2` фиксирует `R∼σ_R²`. Отсюда
$$
\frac{\big|\widehat W_R(k)-G_R(k)\big|}{G_R(k)}=O\big((k\sigma_R)^4\big).
$$
Ведущий коэффициент явный: `|Ŵ/G−1|∼R k⁴/96` (при достаточно малом `k`).
##### (A4) Следствие — гладкость T
1. **UV-подавление.** На ребре зоны Бриллюэна `k→π`: `Ŵ=0`; для `k` порядка `1` (в единицах `1/ℓ_P`) имеем `Ŵ_R≤(cos²(k/2))^R≤e^{−c R}` при `R≫1`. Микроструктура `∼ℓ_P` прибору с радиусом `R` недоступна.
2. **IR = continuum.** Пусть наблюдаемая мода имеет `k∼2π ℓ_P/λ` с `λ≫σ_R ℓ_P`, т.е. `kσ_R≪1`. Тогда `Ŵ_R=G_R·(1+O((kσ_R)^4))`: линейный soft-readout совпадает с свёрткой гауссова ядра ширины `σ_R` до относительной ошибки `O((σ_R ℓ_P/λ)^4)`.
3. **Без `hL→0`.** `ℓ_P` фиксирован; гладкость — свойство **прибора** (`R`), не континуализация M.
На `λ≫σ_R ℓ_P` T-уравнения (§4.1.1: NLSE / GL с `ν_CA`) — эффективное описание того же soft Φ.
##### (B) FCC / hex — path-Green (полное перечисление depth-2)
**Зачем depth 2.** По A1/C3 за один `hT` центр **не** в light-like оболочке. Минимальная чётная глубина, при которой центр снова в support Green — **2** (туда–обратно).
**FCC.** Соседи = 12 перестановок `(±1,±1,0)`. Walks длины 2: `12×12=144`.
Центросимметрия: из `u` шаг `−u` всегда в `N` ⇒ ровно **12** возвратов в `0` ⇒ `w(0)=12/144=1/12`.
Перечисление всех `u+d` (код `fcc_depth2_green_row`): на NN-оболочку приходится **48** walks (`p=1/3`), остальное — дальние оболочки. **Не** `(1,2,1)^{⊗3}`.
**Hex `N₆`.** Аналогично: `6²=36` walks, `w(0)=6/36=1/6`.
Soft Φ = свёртка с этим Green (или его итерациями) — снова C0–C4; класс «поля» тот же, ядро — графовое.
##### (C) Границы теоремы
Доказано: **вынужденность continuum-вида T-readout** + явная ошибка спектра на product-срезе + алгебра depth-2 Green на FCC/hex.
Не покрыто здесь: sim `R`-накопления на живом FCC-поле; PMNS / массы — другой этаж. **Нелинейный hydro-limit** — §4.1.1-HL.
**Ломает:** отказ от C0; block-mean вместо Green; `hL→0` как условие гладкости.

#### 4.1.1 Алгебраический вывод макро-уравнения (NLSE / Ginzburg–Landau)
Вне плотных вихрей (**ρ_E ≪ K_P**) нелинейный замок в gate раскладывается по Тейлору:
```
exp(i·2π·[K_P·(1+1/4π)/(ρ_E+K_P)·Θ_flow − 1])
 ≈ 1 + i·2π·Θ_flow − i·2π·ρ_E/K_P + …
```
Оператор **Σ(…·W)** к обеим частям; дискретные фазовые разности **Θ_flow** по **N** → макро-**∇²**; шаг **Δt = hT**:
```
Φ(X,t+Δt) − Φ(X,t) ≈ l_P² · ∇²Φ(X,t) − i·Δt · (ρ_P c²/K_P) · |Φ|² Φ(X,t)
```
Делим на **Δt**. **c₀ = l_P/Δt = √2·c**, **K_P = ρ_P c²**:
```
∂Φ/∂t = i · (c₀² Δt / 2) · ∇²Φ − i · ω_macro · |Φ|² Φ
```
Подстановка **c₀ = √2·c** схлопывает коэффициент диффузии в **ℏ/(2m)** (размерный квант T-слоя). Получаем **нелинейное уравнение Шрёдингера** / **Ginzburg–Landau** — сверхтекучая квантовая жидкость на **T**, **не** новый M-оператор.
#### 4.1.1-HL · Теорема **T-HL** — hydro/NLSE из накопления FCC depth-2 Green
**Утверждение.** На FCC (`N₁₂`) soft-ядро depth-2 path-Green `K` (§4.1.0-T(B)) изотропно во втором моменте. Накопление `K^{*R}` + gate-Taylor (§4.1.1) + Madelung ⇒ на шкалах `λ≫σ_R ℓ_P` эффективные уравнения **NLSE/GL с вязкостью**, а в гидропеременных — **continuity + Euler с вязким напряжением** (класс Навье–Стокса для Madelung-жидкости). Без `hL→0`.
**Посылки:** C0–C4 · A1 · A3 (M унитарно) · FCC NN · Thm T-CR · gate-Taylor §4.1.1.
##### (H1) Моменты depth-2 Green — полное перечисление
Нормированное ядро `K(p)=#{walks:0→p}/144`. Второй момент:
$$
M_{ij}=\sum_p K(p)\,p_i p_j
=\frac43\,\delta_{ij}
\qquad\big(\mathrm{Tr}\,M=\mathbb{E}[r^2]=4\big).
$$
(Проверка: census walks; off-diagonal численно `∼0`.) Изотропия **forced** кубооктаэдром, не fitted.
Четвёртый: `𝔼[x⁴]=4`, `𝔼[x²y²]=14/9` — не гауссовы (`3M_{xx}²=16/3`); continuum Gaussian — IR-прокси, как в T-CR(A3).
##### (H2) Спектр и накопление `R`
Символ (малый `k`, решёточные единицы `ℓ_P=1`):
$$
\widehat K(k)=\sum_p K(p)\,e^{ik\cdot p}
=1-\tfrac12 k^{\mathsf T}M k+O(|k|^4)
=1-\tfrac23|k|^2+O(|k|^4).
$$
`R` свёрток:
$$
\widehat K^{\,R}(k)=\exp\!\Big(-\tfrac{2R}{3}|k|^2+O(R|k|^4)\Big).
$$
Эквивалентно гауссу с поосевой дисперсией `σ_R²=R·(4/3)` (`exp(−σ²|k|²/2)=exp(−(2R/3)|k|²)`).
**Следствие:** `K−I` в IR действует как
$$
(K-I)\Phi\;=\;\tfrac23\,\nabla^2\Phi\;+\;O(\nabla^4)
$$
(в единицах `ℓ_P`; физически `∇² → ℓ_P²∇²_{\mathrm{SI}}`).
##### (H3) Эффективное уравнение на soft Φ
1. **Унитарная M-динамика** (A3) + gate → локальный фазовый/амплитудный закон (§4.1.1 Taylor).
2. **Soft readout** `Φ=K^{*R}∗z` выносит дискретные разности в `∇²` с коэффициентом (H2).
3. Нелинейность gate на медленном Φ → `−i ω_macro |Φ|² Φ`.
4. Остаток coarse-graining (численная вязкость, §4.1.2) → **вещественный** `+ν ∇²Φ`, не ломая A3 на M.
Итого на T (`λ≫σ_R ℓ_P`):
$$
\partial_t\Phi
= i\,\alpha\,\nabla^2\Phi
\;-\; i\,\omega_{\mathrm{macro}}\,|\Phi|^2\Phi
\;+\; \nu\,\nabla^2\Phi
\;+\; O\big((\ell_P\sigma_R/\lambda)^4\big),
$$
где `α` — из §4.1.1 (`∼ c₀² hT`), `ν=κ_{\mathrm{link}} c₀ ℓ_P` с `κ_{\mathrm{link}}=1/|N₁₂|=1/12` на FCC (срез N₄ даёт `ν=1/4` — другой носитель).
Это **NLSE / комплексный Ginzburg–Landau с вязкостью**.
##### (H4) Madelung → hydro (класс NS)
Положим `Φ=√ρ\,e^{iS/ℏ}` (T-readout). Madelung-разложение (H3) даёт:
- **continuity** с вязкой поправкой к потоку;
- **Euler** для `v=∇S/m` с квантовым давлением `∼∇(∇²√ρ/√ρ)` и **вязким напряжением** `∼ν ∇²v` (плюс объёмные члены от `ω_macro ρ`).
При доминировании вязкого/инерционного баланса над квантовым давлением — **Навье–Стокс** для поля скорости Madelung-жидкости. Квантовое давление — доп. T-член, не отмена класса NS.
##### (H5) Что доказано / что нет
| Утверждение | Статус |
|-------------|--------|
| `M=(4/3)I` на FCC depth-2 | **forced** census |
| `K^{*R}` → Gaussian / `∇²` с ошибкой `O(k⁴)` | **forced** (H2) |
| Gate → `|Φ|²Φ` на soft Φ | **forced** §4.1.1 |
| `ν=1/12` на FCC vs `1/4` на N₄ | **forced** `κ_link=1/\|N\|` |
| Madelung ⇒ continuity+Euler+viscosity | **forced** как тождество map |
| Живой FCC sim `R`-накопления / fit `ω_macro` | **открыто** (T6) |
**Ломает:** отказ от FCC NN; block-mean; требование `hL→0`; подмена `ν` fitted knob вместо `κ_link`.
#### 4.1.2 Эффективная макро-вязкость (T не идеален; M — да)
**Парадокс:** на **M** жидкость **сверхтекуча** и **бездиссипативна** (A3: **`Σ|z|²`** invariant, **`g⁻¹`** существует). На **T** волны **затухают**, есть **трение**, **излучение**, **BH-квазитепло** — макромир **неидеален**.
**Разрешение (Chapman–Enskog над ДА):** диссипация — **не** новый член в **`g`**, а **остаток coarse-graining** при конечных **`Δx = l_P`**, **`Δt = hT`**.

На одном ребре внутри барьера bond-unitary + gate даёт коэффициент передачи амплитуды $\tau\in(0,1)$ (зависит от $\rho$, $\Phi$, не новый knob).

$$

=
\mathrm{e}^{-\kappa L/\ell_P}

\qquad
