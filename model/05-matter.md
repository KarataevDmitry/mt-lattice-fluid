# §5 · Элементарный объём dV и matter

## §5. Элементарный объём dV и планкон (M)
### 5.0 Бинарная плотность M (**`ρ_matter ∈ {0, ρ_P}`**)
**Инверсный переворот:** и **`hV = l_P³`**, и **`hm = m_P`** квантованы жёстко ⇒ **истинная плотность материи** на M **не непрерывна**:
```
ρ_P = m_P / l_P³ = μ_P ≈ 5.155×10⁹⁶ kg/m³
```
Две плотности (A7 vs §5.0):
| символ | смысл | диапазон на M |
|--------|--------|----------------|
| **`ρ_field = ρ_E = μ_P·|z|²`** | энергия **фазового поля** (A7, gate) | **`0…ρ_P`** (потолок A7) |
| **`ρ_matter`** | **масса планкона** в `hV` | **`{0, ρ_P}`** только |
**A5:** вакуум **`ρ_matter = 0`**, но **`ρ_field > 0`** — кипящий фон; **`z ≡ 0`** не устойчив. **`|z|²`** — не «занятость ячейки».
**Занятость `b(x)` — следствие, не knob:**
```
ρ_matter(x) = ρ_P · b(x) , b(x) ∈ {0, 1}
b(x) = ρ_matter(x) / ρ_P = m_cell(x) / m_P
```
**§8.1:** элементарный планкон в **одном** `v_p` ⇒ **`m_cell ∈ {0, m_P}`** ⇒ **`b` уже в §5.0**, не новая аксиома.
**Как выразить `b` через поле `z` (стандартные величины M):**
| канал | формула | § |
|-------|---------|---|
| **масса** | **`b(x) = m_cell(x) / m_P`** | §8.1 |
| **топология (A10)** | **`b(x) = min(1, |n_∂(x)|)`** — **`n_∂`** = дискретный winding на **`∂(hV)`**: канал **rel** **`∮ d arg(z₂/z₁)`** и канал **U(1)** **`∮ d arg(z₁+z₂)`**; readout берёт **больший `|n|`**. (Locked `z₁≡z₂` boil: rel слеп, U(1) видит океан.) | §3.9 · A10 |
| **Arg-дефект (A11)** | pole locked ⇔ **`|Δφ_N(x)| ≥ Δφ_min`** + anti-smear **`K_P`**; **`b=1`** на **ядре** планкон, не на размазанном хвосте | §5.0.1 · §3.7 |
Три строки **эквивалентны** на уровне 0 (один **`m_P`** в одном **`v_p`**). **`n_∂`** и **`|Δφ|`** — **readout из `z`**, не отдельные поля.
На **M** у ячейки **`hV`** только **два** класса **`ρ_matter`**:
| **`b`** | **`hV`** | **`ρ_matter`** |
|---------|----------|----------------|
| **0** | **планковская дырка** ( **`n_∂ = 0`** ) | **0** |
| **1** | ядро планкон **`v_p`** ( **`|n_∂| ≥ 1`**, **`m_cell = m_P`** ) | **`ρ_P`** |
**Macro-иллюзия T:** «вода **1000 kg/m³**», «воздух **1.2 kg/m³**» — **не** микро-плотности ячеек. Это **binomial coarse-grain** (§4.1): в macro-объёме **~1 из 10⁹³** ячеек занято планконом (**`ρ_P`**), остальные — **планковские дырки** (кипящий фон $z$); прибор **усредняет** → «разрежённая» macro-плотность и дальше — **химия** (этаж $k\geq 10$). **Материя не размазана** — **дискретно распределена** по пикселям.
**Следствия:**
| феномен | M | T (иллюзия) |
|---------|---|-------------|
| «плотность материала» | доля занятых **`hV`** | **`kg/m³`** continuous |
| предел сжатия | **`ρ → ρ_P`** монолит | VdW **`b`**, §5.3.3 |
| «сингулярность» BH | **нет `ρ > ρ_P`:** монолит — все пиксели = 1 | continuum **`ρ → ∞`** |
#### 5.0.1 Истинный переносчик массы: квант **`Arg`-давления** (не Higgs)
**SM-мacro:** бозон Хиггса = «податель массы» — частицы **вязнут** в непрерывном scalar-поле.
**M (ДА):** масса **не** рождается полем Хиггса. Macro-масса = **эффективное замедление** — частота **внутренних отражений зигзага** планкон **`hV`** в **`K_P`**-жидкости (§5, §3.7). Плотность квантуется **`ρ ∈ {0, ρ_P}`** (§5.0) — не continuous «вязкость в Higgs».
**Истинный M-переносчик инерции** — не частица с объёмом, а **квант фазового натяжения** на каждом **`hV`**:
```
Δφ_N = Arg( ⟨z⟩_N / z ) wrapped ∈ (−π, π]
```
Тот же член, что в gate §3.9.2 · impl: **`holonomy_zeta`**, **`wrapped_phase_diff`**.
**Механизм зигзага:**
1. безмассовый **каузальный** перенос по **N** (`c₀` по осям);
2. натыкается на **`K_P`** + нелинейный gate → **разворот** фазы в ε-окрестности **`v_p`**;
3. **`Arg`-поток** **передаёт** фазовый сдвиг по соседям и **запирает** энергию в ячейке → macro-readout **`m_rest`**.
**Хиггс на T:** не первопричина, а **вторичная macro-структура** — **пена** на **`Arg`-океане**. Масштаб (**§8.3.1**):
```
m_H = m_P · α_fs⁸ · √(π/2) = v/2 ≈ 123 GeV
```
(`v = α_fs⁸ E_P √(2π)` уже §8.4.1; топология §8.3.1: `m_H = v/2`, `λ=1/8` SM-readout). LHC видит **флуктуацию T**, не micro-механизм.
| слой | «кто даёт массу» |
|------|------------------|
| **M** | **`Arg(⟨z⟩/z)`** + **`K_P`** + зигзаг в **`hV`** |
| **T** | **`m_rest`** readout; **Higgs** = macro-возбуждение поля плотности |
| **SM fit** | **`m = m_P α_fs² f_геом`** (§8.2) — check topology, не Higgs-knob |
#### 5.0.2 Фундаментальный квант фазового действия **`s₀`** (переносчик **`Arg`**)
**`Arg`-поток** — безмассовый калибровочный квант **фазового натяжения** на одном **`hV`**, но его **действие за один M-тик** квантуется из геометрического затвора §3.7.2:
```
Δφ_min = ½ rad (Heisenberg floor — impl: heisenberg_phi_min)
s₀ = ℏ · Δφ_min = ℏ/2 ≈ 5.272×10⁻³⁵ J·s
```
**Истинная энергия одного кванта** за M-тик **`hT = t_P/√2`** (§7.1):
```
E₀ = s₀ / hT = (ℏ/2) / (t_P/√2) = (1/√2) · ℏ/t_P = E_P / √2
E_P = ℏ/t_P ≈ 1.956×10⁹ J
E₀ ≈ 1.383×10⁹ J ≈ 8.63×10²⁷ eV
```
**Локальный энергетический эквивалент на пиксель** (не «масса частицы», а **`E=mc²`** на **`hV`**):
```
m_arg = E₀/c² = m_P / √2 ≈ 1.538×10⁻⁸ kg
ρ_cell = m_arg / v_hV = m_P / ℓ_P³ = μ_P (§7.3 — Planck из условий на ячейку)
```
**Скорость переноса** — **не** macro-свет **`c = c₀/√2`** (fractal T-зигзаг), а **чистая тактовая скорость CA** по каузальным осям **`N`**:
```
v_arg = c₀ = l_P/hT = √2 · c ≈ 4.24×10⁸ m/s
```
| величина | формула | SI (CODATA) | vs Higgs |
|----------|---------|-------------|----------|
| **`s₀`** | **`ℏ/2`** | **5.27×10⁻³⁵ J·s** | — |
| **`E₀`** | **`E_P/√2`** | **~1.38×10⁹ J** | **~8.6×10²⁷ eV** |
| **`m_arg`** | **`m_P/√2`** | **~1.54×10⁻⁸ kg** | micro-эквивалент, не rest mass |
| **`v_arg`** | **`c₀`** | **√2·c** | **> c** (M-такт, не macro-photon) |
| Higgs (T) | macro fluctuation | **~1.25×10¹¹ eV** | **~10¹⁶× слабее `E₀`** |
#### 5.0.3 Антиматерия: геометрическая инверсия **`n → −n`**
**SM-мacro:** антивещество — «другое вещество», рождение парами, загадка baryon asymmetry.
**M (ДА):** античастица — **тот же** солитон **`hV`**, **зеркальное** фазовое вращение:
| | частица | античастица |
|---|---------|-------------|
| обход **`N`** | **`+2π`** (правый вихрь) | **`−2π`** (левый) |
| топокласс | **`n = +1`** · `VORTEX_P` | **`n = −1`** · `VORTEX_M` |
| объём | **`hV`** | **`hV`** (тот же) |
| **`m_rest`** | зигзаг + **`K_P`** | **то же** — **`K_P`** не различает знак вращения |
| **заряд T** | **`+e`** | **`−e`** — направление **`Arg`-потоков** инвертировано |
**Аннигиляция (e⁺ + e⁻ → 2γ)** — не «уничтожение материи», а **алгебраическая компенсация** топологии:
```
n = +1 + n = −1 → n_net = 0 (фазовые градиенты противоположны, ±2π схлопываются)
```
1. два вихря сближаются на **`N`** → **`Arg`-градиенты** накладываются **в противофазе**;
2. **топологический замок** (Heisenberg + **`K_P`**) **исчезает** — среда возвращается к **гармоническому вакууму** `n=0`;
3. запертая энергия **не уничтожается** (A3) — уходит **двумя** macro-волнами давления со **`c = κ·c₀ = c₀/√2`** — **T-фотоны** (§1.1 · теория излучения §8.2).

##### Канал аннигиляции — формулы (кто → куда)
**Не** распад одного узла. Класс хода: встреча пары `±` (§8.2 теория распада · отличие от распада).
**T-имя:**
$$
e^{+} + e^{-} \;\longrightarrow\; \gamma + \gamma
$$
**M-имя (то же событие):**
$$
\bigl(n=+1,\,b=1,\,Q=+e\bigr)
\;+\;
\bigl(n=-1,\,b=1,\,Q=-e\bigr)
\;\longrightarrow\;
2\times\bigl(n=0,\,b=0,\,Q=0\bigr)
$$
**Инварианты:**
$$
\begin{aligned}
n_{\mathrm{net}}&:\; (+1)+(-1) \to 0,\\
Q&:\; (+e)+(-e) \to 0+0,\\
N_\gamma&:\; 0 \to 2,\\
E&:\; E_{+}+E_{-} = E_{\gamma_1}+E_{\gamma_2}
\quad(\text{ledger }n_E E_0,\;A3).
\end{aligned}
$$
**Каждый γ на M:**
$$
\gamma:\quad n=0,\quad Q=0,\quad E=n_E E_0,\quad
|\mathbf{v}|=c=\kappa\,c_0=c_0/\sqrt{2}.
$$
**CM покоя пары (схема энергии):**
$$
E_{\gamma_1}=E_{\gamma_2}=m_{\mathrm{rest}}c^{2}
\quad\Rightarrow\quad
\mathbf{p}_{\gamma_1}=-\mathbf{p}_{\gamma_2}.
$$
Два фронта в разные стороны; «кольца» — T-картинка перекрытия фаз вблизи точки (T2: два пакета → интерференция, не mush). Океан локально → гармонический вакуум `n=0`; A5-кипение фона не гаснет; избыток не сжимается in-place — gate выталкивает волной (§5.1.1).
**Запреты рядом:**
$$
e^{-}\not\to\text{ниже при том же }Q
\quad(\text{топо-защита одиночного }n=\pm1);\qquad
\gamma\not\to\text{ниже}
\quad(\text{уже }n=0\text{-сектор}).
$$

##### Углы и поляризации 2γ (M → T)

**Не** отдельный S-matrix. Кинематика + геометрия $\Phi_\square$ / SU(2) на том же канале §5.0.3.

**1 · Micro (M): ось и рёбра**

Встреча на $N(x)$: относительный импульс задаёт **ось столкновения** $\hat{\mathbf{n}}$ (единичный вектор вдоль $\mathbf{p}_+-\mathbf{p}_-$ в CM). Gate выталкивает два $n=0$-фронта **вдоль противоположных light-like направлений** на $\Lambda$:
$$
\hat{\mathbf{k}}_1=+\hat{\mathbf{n}},
\qquad
\hat{\mathbf{k}}_2=-\hat{\mathbf{n}},
\qquad
\hat{\mathbf{k}}_i\in\mathrm{span}\{\hat e_j:\,\hat e_j\in N(x)\}
$$
(один hop за $hT$ по $\hat e_j$ с $|\hat e_j|=l_P$; macro-скорость $c=\kappa c_0$, §1.1). Азимут вокруг $\hat{\mathbf{n}}$ — **свободная фаза** пакета (U(1)$_\mathrm{vac}$, §3.11), не новый knob.

**2 · CM (T-readout кинематика)** — уже выше; дополняем импульс:
$$
|\mathbf{p}_{\gamma_i}|=\frac{E_{\gamma_i}}{c}=m_{\mathrm{rest}}c,
\qquad
\mathbf{p}_{\gamma_1}+\mathbf{p}_{\gamma_2}=0.
$$

Для **неподвижной** пары в CM направление $\hat{\mathbf{n}}$ **фиксировано** начальным состоянием; «кольца» вблизи точки — T2 (интерференция двух пакетов), не второй закон углов.

**3 · Изотропия $d\sigma/d\Omega$ (macro, A12 · T1)**

На одной оси micro-анизотропия $N_{12}$; macro-наблюдатель — binomial $(1{-}2{-}1)$ + $\kappa=1/\sqrt{2}$ (§4.1 · §8.2) → **изотропный** световой конус. Для **равновесного / неполяризованного** ансамбля пар (случайная ориентация $\hat{\mathbf{n}}$ в лаборатории, §2.1 coarse ensemble):
$$
\left\langle\frac{d\sigma}{d\Omega}\right\rangle
=
\frac{\sigma_0}{4\pi},
\qquad
\int d\Omega\,\frac{d\sigma}{d\Omega}=\sigma_0.
$$
$4\pi$ — **телесный угол emergent 3D** (§1.4.3), не $|N_{12}|$. Абсолютное $\sigma_0$ и boost-аберрация — **T-калибровка** (не новый закон $g$).

**4 · Поперечность и $g_{\mathrm{pol}}=2$**

Фотон = $n=0$-фронт голономии $\Phi_\square$ (§8.2). На 1-tick hull кубооктаэдра — **6** квадратных □-граней; дискретный Stokes:
$$
\Phi_\square=\sum_{e\in\partial\square}\Delta\varphi_e,
\qquad
B_\square=\Phi_\square/\ell_P^{2},
\qquad
\sum_{\partial\square} E_e\,\ell_P=-\Phi_\square.
$$
Поляризационный вектор T — **поперечное** возмущение $\Phi_\square$ в плоскости грани □, **перпендикулярно** $\hat{\mathbf{k}}$ (macro $\nabla\cdot\mathbf{B}=0$). В emergent $d=3$ у каждого $\hat{\mathbf{k}}$ ровно **две** независимые поперечные оси →
$$
g_{\mathrm{pol}}=2
$$
(фактор в $u(\omega)$ и занятости мод; §8.2). Продольная мода на T **не** входит в Maxwell-readout.

**5 · SU(2) и корреляция $\hat{\epsilon}_1\perp\hat{\epsilon}_2$**

Пара $e^+e^-$ — два спинорных вихря $z\in\mathbb{C}^2$ (§3.10). Bloch-ось $\mathbf{s}=z^\dagger\boldsymbol{\sigma}z/|z|^2$; при обходе $hV$: $2\pi\to-1$, $4\pi\to+1$.

| начальное $S$ | канал | поляризации 2γ |
|---------------|-------|----------------|
| **синглет** $S=0$ ($^1S_0$, para-Ps) | **$2\gamma$** | $\hat{\epsilon}_i\perp\hat{\mathbf{k}}_i$; **$\hat{\epsilon}_1\cdot\hat{\epsilon}_2=0$** |
| **триплет** $S=1$ ($^3S_1$, ortho-Ps) | **$3\gamma$**, не $2\gamma$ | C-отбор: два фотона не закрывают spin-1 |

**Вывод синглета (схема, не postulate):** $C$ чётная для $e^+e^-\to\gamma\gamma$; при $J^{PC}=0^{++}$ поляризации линейны и **взаимно ортогональны** в CM. На M: антипараллельные $\mathrm{Arg}$-градиенты $n=\pm1$ схлопываются в скаляр SU(2) (синглет на $v_p$) → остаются два независимых поперечных □-канала, **не** одна общая линейная поляризация.

Для **неполяризованного** пучка / thermal readout: усреднение по Stokes → нет предпочтительной $\hat{\epsilon}$ (§2.1).

#### T-статистика (readout, не закон $g$)

**Смысл (§2.1):** на M каждый тик вычислим; «случайность» и $N(t)=N_0 e^{-t/\tau}$ — **грубый прибор + ансамбль**.

| T-величина | на M | T-readout / PDG |
|------------|------|------------------|
| $\Gamma=\hbar/\tau$ | нет float-Γ | статистика многих одинаковых систем |
| $\tau$ para-Ps | $n_{\mathrm{ticks}}\cdot hT$ только после **sim-open** bound state | PDG $\tau\approx 125\,$ps |
| $d\sigma/d\Omega$ | ось столкновения фиксирует dipole | $\langle d\sigma/d\Omega\rangle=\sigma_0/(4\pi)$ при random $\hat{\mathbf{n}}$ |
| $\mathrm{BR}(2\gamma)$ vs $3\gamma$ | SU(2)+C (§выше) | ortho-Ps → $3\gamma$ |

**Probe (dogfood):** `mt_ca/annihilation_t_stats.py` · verify **`Annihilation_T_stats`**.

- Путь: head-on dual Gaussian (T2-аналог двух macro-фронтов); **vortex $e^+e^-$ на torus** с глобальным winding — **sim-open**.
- **$\tau_M$:** `tick_focus · hT` (порядка $10^{-42}\,$s при $hT=t_P/\sqrt{2}$) $\ll \tau_{\mathrm{para\text{-}Ps}}$ — нужен мост **bound state** (Compton/$a_0$ ladder), не новый knob в $g$.
- **Back-to-back (одно событие):** `elongation_delta>1`, `peaks_on_delta≥2` на coarse $\Delta\Phi$ — dipole, не сфера.
- **$\langle d\sigma/d\Omega\rangle$:** равномерный ансамбль вращений оси; точное совпадение измеренной оси с вложенной на hex — **open** (интерференция/fringes).

**Открыто (не закон M):** $\Gamma,\tau,\mathrm{BR}$, абсолютное $\sigma_0$; fine structure $d\sigma/d\Omega$ при поляризованных пучках; vortex-pair live sim; readout-axis на FCC/hex.

**Baryon asymmetry (§9.2 Phase IV→I):** не «50/50 случайность». M **детерминирован** (§2.1): первый A5-сдвиг «лёда» задаёт **хиральность** пузыря — **доминирует `n=+1`**. Антиматерия **локально** рождается (коллайдер, U-вихрь), но живёт в **«правой воде»** — быстро встречает **`n=+1`** фон → annihilation. **«Левые круги на правой воде»** — не мистика, а **геометрия стартового зародыша** (§9.7: какой класс «наш»).
**Объём ячейки:**
```
dV = (dl)³ , dl = l_P = const
```
Один **элементарный** планкон **локализован в одном `v_p = dV`** — одной планковской ячейке решётки.
**Параметры `v_p`-частицы (уровень 0) — не гипотеза модели.** Это **Planck-арифметика уже сейчас**: подставь измеренные `ℏ, G, c, e` → числа (§7). Модель **помещает планкон в один `v_p`**, а не «обещает вычислить потом».
```
v_p = dV = (dl)³
m₀ = m_P = √(ℏc/G) ≈ 2.18×10⁻⁸ kg
e₀ = e ≈ 1.602×10⁻¹⁹ C
ν₀ = 1/hT ≈ 2.62×10⁴³ Hz
u₀ = u_P = K_P = c⁷/(ℏG²) ↔ |z|² = 1 в natural
c₀ = dl/hT = √2·c
```
Свободных «новых» констант на этом уровне **нет** — только `ℏ, G, c, e` (измерены) + целый `n` (топология).
**Если структура занимает больше одного `v_p` на фундаментальном уровне — это уже составная структура** (узел из нескольких планконов), не элементарная частица.
**Топология:** vortex charge `n ∈ ℤ` (U(1)); **спинорный полуоборот** при обходе **`hV`** → **SU(2) sign** (§3.10).
**Паули на одном `v_p`:** два fermionic планкона с совпадающим спинором **запрещены** — **`K_P`** выталкивает (§3.10.4).
**Самозахват:** gate `φ` запирает фазовый дефект внутри одного dV.
**Зигзаг → масса (T):** **`Arg`-запирание** + внутренние отражения в ε-окрестности **`v_p`** → macro **`m_rest`** (§5.0.1).
#### 5.0.4 Орбитали / запрещёнка на планконе
**Ход из атомной / ядерной физики.** На Å-масштабе: дискретные уровни энергии, орбитали, правила отбора, запрещённые переходы, запрет Паули, запрещённые зоны в кристалле. Квантование **не выключается** при спуске к `l_P`.
У планкона уже есть **масса и энергия** (§5.0.2, §8.1): **`E₀`**, **`m_arg`**, **`m₀∼m_P`**, частота **`ν₀=1/hT`**. Значит у неё **та же логика запрещёнки** — иначе «квантуется всё, кроме планкона» = дыра в лестнице.
**Чего нет:** орбиталей *внутри* `hV` как облака на `r < l_P`. Ниже `dl` пространства нет (§0, §1). Не Bohr радиус внутри пикселя.
**Что есть вместо «орбиталей атома»** — дискретные степени свободы планкона и его ε:
| атом / ядро (T) | планкон на M |
|-----------------|------------------|
| уровни `E_n` | **`E = n_E·E₀`**, `n_E∈ℤ` (§5.2); тики **`Φ`** на **`N_ring`** |
| орбитали (`n,ℓ,m`) | **внутренние:** фаза на кольце + спинор **SU(2)** / хиральность; **внешние:** оболочки соседей (1-я, 2-я координационная сфера Λ) — tight-binding на звезде ε, не континуум внутри ячейки |
| запрет Паули | **A16 / §3.10.4:** два одинаковых спинора в одном **`v_p`** запрещены; **`b∈{0,1}`** |
| запрещённый переход | смена состояния, не кратная кванту (`E₀`, `Δφ_min`, `G`/`p₀`) или ломающая топологию/`n` без партнёра |
| запрещённая зона (ФТТ) | щели спектра **`ω(k)`** на зоне Бриллюэна вакуума (§5.2.4); между уровнями **`n_E`** |
**Bekenstein:** конечный бит-бюджет **`B_hV`** (§3.12.6) ⇒ конечное число внутренних состояний ячейки — «орбитальный» гильберт планкона **конечен**, не `L²(ℝ³)` внутри `hV`.
**Склейка:** атомные орбитали электрона — T-картина **составного** узла; планкон несёт **зародыш** той же запрещёнки (Паули + дискрет `E`/`Φ` + оболочки Λ). Укрупнение (§1.5, §6) размножает уровни, не изобретает квантование с нуля.

**Детализация этажа 0 (внутренний спектр):** [`05-floor0-spectrum.md`](05-floor0-spectrum.md) — landmarks на $\mathbb{Z}_{512}$, ground vortex, SU(2) $2\pi/4\pi$; verify **`Brick_internal_spectrum`**.
#### 5.0.5 Гейзенберг ⇒ аналог электронной плотности
**В атомной QM:** электронная плотность `ρ_e(r) = |ψ|²` — не δ-функция в точке ядра: Гейзенберг + связанные состояния размазывают облако. Интеграл = число электронов; пики и хвосты = химия / ФТТ.
**У нас свой Гейзенберг (§3.7):** `Δφ ≥ Δφ_min = ½` на голономии — фазовый дефект **нельзя** сжать до «бесконечно острый Arg». Значит и у пра-материи должна быть **плотность-облако**, не только бит «ячейка занята / нет».
Слои плотности:
| поле | что это | аналог |
|------|---------|--------|
| **`\|z\|²` / ρ_E** | энергоплотность **среды** (океан кипит везде) | не `ρ_e` — скорее «эфир / вакуум» |
| **`b ∈ {0,1}`** на ядре | топологическая занятость `hV` (§5.0) | жёсткий скелет «здесь узел» |
| **`ρ_Θ` (новое имя)** | **облако** вокруг узла: где `|Δφ|`, `|ζ|`, holonomy / Arg-давление держатся ≥ Гейзенберг-пола | **`ρ_e`** |
```
ρ_Θ(x) ∝ f( |Δφ_N(x)| , |ζ(x)| ) с полом Δφ_min
⟨ρ_Θ⟩_T = binomial coarse → «электронная» / matter-density readout
∫ ρ_Θ ∼ n_E / топозаряд (норма облака кратна кванту, не float-KN)
```
**Следствие Гейзенберга:** минимальный **пространственный** хвост облака — хотя бы ε-окрестность (соседи Λ): нельзя иметь `ρ_Θ` = δ на одном `v_p` *и* нулевую фазовую неопределённость. Anti-smear (`K_P`) держит ядро; Гейзенберг держит **неустранимый ореол**.
**Склейка к §5.0.4:** орбитали-оболочки = моды этого `ρ_Θ` на координационных сферах; запрещёнка = какие формы облака / переходы облака разрешены.
### 5.1 Пространство = **несжимаемая** lattice fluid
**Меньше `v_p` не существует** (§1, §5) ⇒ **`v_p` несжимаем** — минимальный квант объёма. Не «пустота между точками», а **заполненные до краёв** ячейки.
**Пространство — идеальная комплексная спинорная квантовая жидкость** на константных пикселях `(hL, hT)`:
| Образ | M | аксиома |
|-------|---|---------|
| **Океан / вакуум** | базовое кипение, boulon + gate | A5, §10.2 |
| **T (macro)** | **гидродинамика** поля `z` — волны, front, coarse | §4 |
| **Частица** | устойчивый **водоворот** (vortex/soliton) в `v_p`… | §5, §9.7 |
| **Масса** | **`Arg`-зигзаг** + **`K_P`**-отражение в **`hV`** (§5.0.1) | §5 |
| **Энергия / объём** | **не сжать** — только **перемешать** | A3 `Σ|z|²`, A6 |
```
несжимаемость ↔ фиксированный v_p + сохранение нормы (A3)
«пустоту» искали — среда изначально полная; |z|→0 недостижим (A5)
```
**Не «просто метафора»:** см. §5.2 — Madelung-изоморфизм на дискретной решётке. Имя репо **`mt-lattice-fluid`** — онтология M.
### 5.1.1 Сопротивление сжатию (модуль упругости среды)
**Несжимаемость** — не только «фиксированный `v_p`». Нужен **ответ среды** на попытку локально изменить «плотность» информации. В continuum — **модуль объёмной упругости** / давление на сжатие. В M его роль несёт **нелинейный gate** `𝒩(z)` (§3.4), не отдельный fitted knob.
**Базовое давление (жидкость заполнена):** `ε = 1` ↔ **`u_P`** — фоновый модуль покоя, «заполнено до краёв» (§7.1). В natural: знаменатель `|z|² + ε` при равновесии вакуума.
**Сопротивление деформации:** локальное отклонение `ρ = |z|²` от фона → скобка gate:
```
φ = 2π · ( (1+r) / (ρ + ε) − 1 ) · w(ρ) , r = 1/(4π)
```
Чем сильнее «сжать» или «разредить» ячейку, тем **жёстче** фазовый доворот `exp(iφ)` — среда **возвращает** к вакуумному балансу (A5, A7). Это **цифровой аналог** колоссального ответного давления несжимаемой жидкости; перенос избытка — не сжатие, а **волновой фронт** или **vortex** (§5.2).
**Связь с κ (упругость ↔ скорость волны давления):** геометрия N задаёт **`κ = 1/√2`**. С **`hT = t_P/√2`** (§7.1):
```
c = κ · c₀ — macro скорость «звука»/света на T (CODATA)
c₀ = l_P/hT — тактовая скорость передачи по осям M
```
**`κ` — не подгон:** коэффициент **геометрии ε** (macro-изотропия из каузального многогранника FCC / гекс). Отдельно от **`r`, `1+r`, `ε`** (насыщающая фаза).
#### Размерный модуль упругости **`K_P`** (не fitted)
Macro-волна давления несжимаемой жидкости = **свет** со скоростью **`c`** (CODATA). Гидродинамика:
```
c² = K / ρ_mass ⇒ K_P = μ_P · c²
```
| символ | формула (СИ) | значение |
|--------|--------------|----------|
| **`μ_P`** (mass density fluid) | `c⁵/(ℏG²)` | `≈ 5.155×10⁹⁶` kg/m³ |
| **`K_P`** (bulk modulus) | **`μ_P·c² = c⁷/(ℏG²)`** | **`≈ 4.633×10¹¹³` J/m³ (Pa)** |
**Сшивка с gate:** **`K_P = u_P`** = **`β`** в размерном уравнении §7.1. Не новая константа — **тот же** Planck-барьер: **`K_P = μ_P·c² = c⁷/(ℏG²)`**.
```
|z|² = ρ_E / u_P , ε = 1 ↔ ρ_E = u_P = K_P (natural floor)
```
**Нотация:** **`μ_P`** [kg/m³] · **`u_P`** [J/m³] · **`K_P`** [Pa], **`K_P = μ_P·c² = u_P`**.
**Вязкость (второй параметр среды):** A5-кипение — **микро-вязкость**; на **T** — emergent **`ν_CA = κ_link·c₀·l_P` (= `c₀·l_P/|N|`)** из coarse-graining §4.1.2 (**не** член в **`g`**). Isotropic streaming (§3.6) ≠ замена **`ν_CA`**.
| параметр | роль в fluid | M |
|----------|--------------|---|
| **`K_P = μ_P·c² = u_P`** | модуль объёмной упругости вакуума | **`c⁷/(ℏG²)`** §5.1.1 |
| **`ε`, `r`, `1+r`** | насыщающая фаза | `φ(ρ)` |
| **`κ = 1/√2`** | геометрия N → `c = κ·c₀` | §1.1, §7.1 |
| **A5 кипение** | микро-вязкость | `|z|≫0` вакуум, не ламинар |
| **`γ = κ_link = 1/4`** | кинетическое смешивание по **`N`** | §5.2.2 · `bond-unitary` |
### 5.2 Гидродинамика M → T (Madelung на **ε**)
**Опора (Madelung 1926):** (1926) — непрерывное уравнение Шрёдингера **эквивалентно** уравнениям Эйлера для жидкости с «квантовым потенциалом». Madelung — в **continuum**; мы переносим принцип на **дискретный** CA при фиксированных `(hL, hT)`.
**ε-окрестность:** поток и `div_disc` — на **ε** (не Moore; в ночном черновике было «Мур» — **снято**, A1).
#### Неразрывность (M vs T)
**M (дискретно):** A3 — глобальная норма `Σ_x |z|²` invariant. Локально плотность `ρ = |z|²` меняется только **перетоком** по связям / реестр импульса (целые кванты), не «плавным» PDE. Мир планковский — **нет** континуум-закона на клетке.
**T (эмерджентно):** гладкая неразрывность Madelung
```
Δρ/Δt + div_disc(j⃗) ≈ 0
```
— **readout** после coarse-grain / одного тика как диагностика (§4.3). Не hard-claim на `g`. Residual на leapfrog 2-го порядка — ожидаем, не «дыра M».
`j⃗` — дискретный поток по связям **N** (T-имя поверх M). Аналог **сохранения объёма** несжимаемой жидкости на T: fluid не исчезает — **перемешивается**.
#### Давление / импульс — gate `𝒩(z)` (модуль сопротивления)
Роль **давления** и **сопротивления сжатию** — **нелинейный gate** `φ(|z|²)` (§3.4, §5.1.1, §7.1):
- `ε = 1` — базовая «заполненность» жидкости (несжимаемый фон);
- отклонение `ρ` от фона → `(1+r)/(ρ+ε) − 1` — **упругий** фазовый ответ;
- избыток не сжимается in-place — уходит **волновым фронтом** (`n=0`, §9.7) или **закручивается** в vortex (massive, зигзаг §5).
Effective **Euler / Navier–Stokes на T** — coarse-grain над этим M-слоя; полный дискретный NS **не** записан буквально — **структурный** изоморфизм, численно через T-readout.
#### Вязкость и «квантовая пена»
A5: абсолютный ноль недостижим → жидкость **никогда ламинарна** на M. Микро-турбулентность = вечное кипение boulon + gate. На **T** — нулевые колебания вакуума, `|Ψ|²`-шум coarse-grain (§2.1).
| Madelung (continuum) | M (дискрет) | T (macro) |
|----------------------|-------------|-----------|
| плотность ρ | `\|z\|²` | `\|Φ\|²` binomial macro (§4.1) |
| поток j | bond flux N | macro current from **Φ** |
| квантовое давление | gate `φ`, **`ε`, `r`, `1+r`** (§5.1.1) | effective pressure |
| модуль упругости → `c` | **`κ = 1/√2`**, `hT` (§1.1, §7.1) | macro `c` |
| вязкость / нуль | A5 кипение (§5.1.1) | vacuum fluctuations |
#### 5.2.1 Локальные законы · кванты **p, L, F** · **SO(2)** (Теорема 5.1)
### Теорема 5.1 — Механика из аксиом (Landau, не postulate **p/F**)
**Утверждение:** после **Thm 0.1** (носитель) и **Следствия 0.7** (**`g`**) локальные **механические** величины на **`hV`** — **единственная** лестница **`s₀→p₀→L₀→F₀→E₀`**. Не три fitted knob. **Следствие 0.8** — краткая форма в §0.
| лемма | из | следствие |
|-------|-----|-----------|
| **5.1a** | **A5 · §3.7** | **`s₀=ℏ·Δφ_min=ℏ/2`** |
| **5.1b** | **Thm 0.1 · §7.4** | **`p₀=s₀/hL`**, **`E₀=s₀/hT`**, **`m_arg=E₀/c²`** |
| **5.1c** | **§5.2.1** | **`L₀=s₀`**, **`g_M=c₀/(2hT)`**, **`F₀=m_arg·g_M`** |
| **5.1d** | **A3 · A13 · §3.12** | **`⌊𝒩⌋`** ⇒ **`Δp∈p₀·ℤ`**; float **`∫ Im(z*∇z)`** — только T |
| **5.1e** | **§5.2.2** | **`E₀=p₀·c₀=F₀·hL`**, **`E=n_E·E₀`** |
**Ошибка continuum-мышления:** считать **`p, L, F`** float-интегралами **`∫ Im(z*∇z)`** и искать их сохранение в ℝ. На M это **T-чтение**. На M — **целые кванты** той же лестницы, что **`s₀`** и **`⌊𝒩⌋`**.
**Посылка (теорема, не postulate):** **`s₀ = ℏ·Δφ_min = ℏ/2`** (§5.0.2 · **Thm 5.1a**) — минимальное **действие** одного **`Arg`-события** на **`hV`** за **`hT`**. **`hL`, `hT`** — **Thm 0.1**. **Всё механическое квантуется** — не три отдельных аксиомы.
##### Лестница (Planck-арифметика, без knobs)
```
p₀ = s₀ / l_P = ℏ / (2 l_P) = m_arg · c₀/2 — импульсный квант
L₀ = p₀ · l_P = s₀ = ℏ/2 — моментный квант
g_M = c₀ / (2 hT) = l_P / (2 hT²) — M-ускорение «клетка за тик²»
F₀ = p₀ / hT = m_arg · g_M — **F = mg** на одном hV
```
**Красота (§5.0.2 + §5.2.1):** не три разных knob — **одна** лестница **`s₀`**. Импульс **`p₀`**, масса **`m_arg`**, ускорение **`g_M`**, сила **`F₀`** связаны **ньютоновски**:
```
p₀ = m_arg · (c₀/2) , v_half = c₀/2
F₀ = m_arg · g_M , **F = mg**
ΔF = Δm · g , Δm ∈ m_arg·ℤ , g = g_M (локально на hV)
```
**`E₀/c₀ = p₀`** — это **импульс**, не сила. **`F₀ = E₀/(c₀·hT) = p₀/hT`**.
| M-заряд | квант | SI (CODATA) |
|---------|-------|-------------|
| **`p`** | **`n_p · p₀`**, **`n_p ∈ ℤ`** | **`~½ m_P c`** |
| **`L_z`** | **`n_L · L₀`**, **`n_L ∈ ℤ`** (полуцелое при spin) | **`ℏ/2`** |
| **`F`** | **`n_F · F₀`**, **`n_F ∈ ℤ`** | **`~ c⁴/G`** (Planck force) |
**Связь с §3.12:** **`⌊𝒩⌋ ∈ ℤ_{N_ring}`** — не «дрейф float-импульса», а **передача целого числа **`p₀`-пакетов** между **`v_p`** и **`N(v_p)`** за **`hT`**. Kick ledger = **локальная бухгалтерия** **`Δp ∈ p₀·ℤ`**.
##### Локальная неразрывность (A3 на звезде **`N`** · гладкое — T)
**M:** A3 глобально — **`Σ_x |z|² = const`**. Локально на **`v_p`** — только **дискретный** переток / реестр импульса (целые пакеты), не PDE на клетке.
**T (не M-закон):** гладкая запись Madelung
```
Δρ(x)/Δt + div_disc j⃗(x) ≈ 0
```
— эмерджентный readout (§4.3).
**Bond-flux** на ориентированной связи **`x → x+ê_i`** (natural units, T-имя поверх M):
```
j_i(x) = Im( z*(x) · z(x+ê_i) ) / hT
div_disc j = Σ_i [ j_i(x) − j_i(x−ê_i) ]
```
| слой `g` | что на M | что на T |
|----------|----------|----------|
| **bond-unitary** `bond-unitary` | каждая 2×2 link-mix сохраняет **`|a|²+|b|²`** на паре | `div_disc j≈0` по **`ρ`** как readout |
| **isotropic gate** `z'=z·exp(iφ)` (§3.6 default) | **`ρ(x)`** не меняется in-place; импульс — в фазовом **`π`** | Madelung residual — T |
| **leapfrog + ⌊𝒩⌋`** (§3.12) | **`ρ`** mod **`N_ring`**; импульс — **целые** kick на ledger | one-tick Madelung residual ожидаем (2nd order) |
DFT/spectral — только калибровка T (§3.5). **Гладкая непрерывность на M не требуется** — планковский мир дискретен по определению.
##### Локальное сохранение импульса
**Импульсная плотность** (дискретная, 2D):
```
π^a(x) = Im( z*(x) · [z(x+ê_a) − z(x−ê_a)] ) / (2 hT) a ∈ {x,y}
```
**Локальный баланс** на звезде **`N(x)`** (изотропный gate + projected kick):
```
Σ_{y∈N(x)} Δπ^a(y) = 0 (mod p₀) за один hT на каждой оси a
```
**Смысл:** gate **`φ`** собран только из **SO(2)-скаляров** в точке **`x`** (**`ρ`**, **`ζ=(Σ_Nz)·z*`**, **`Δφ`**). Нет preferred axis → **отдача** соседям **симметрична**; **«сила»** **`F = Δp/hT`** — **целое **`n_F·F₀`**, не утечка в continuum.
##### **SO(2)** — вывод, не «квадрат ломает круг»
**1 · Изотропная звезда.** **`N(x) = {x±ê_x, x±ê_y}`** с **равными** весами в **`Σ_N`** (§3.6). Нет выделенной оси в **локальном** правиле.
**2 · SO(2)-скалярный gate.** Под **поворотом плоскости** **`R_θ ∈ SO(2)`** (на решётке: **`θ = k·π/2`**, **`k∈ℤ`**) поле **`Ψ`** и соседи **вращаются вместе**:
```
φ(R·Ψ) = φ(Ψ) ⟹ g(R·Ψ) = R·g(Ψ)
```
**`ρ`**, **`|ζ|`**, **`Δφ`** — **скаляры**; **`exp(iφ)`** — **U(1)-поворот** спинора в **`v_p`**. **Локальная** динамика **SO(2)-ковariantна**.
**3 · Noether → **`L_z`**. Генератор **`SO(2)`** — **момент**:
```
L_z(x) = ε_{ab} x^a π^b(x) → L_z = Σ_x L_z(x) ∈ L₀ · ℤ
```
**Локально:** **`ΔL_z(x)/Δt + div j_L(x) = 0`** (дискретный аналог); **`j_L`** — **угловой поток** по связям **`N`**.
**4 · **`C₄` vs `SO(2)`** — одна ось, два разрешения:**
| слой | SO(2) |
|------|-------|
| **M** | **локальная** **`SO(2)`**-ковariantность + **`L_z ∈ L₀·ℤ`**; на торе **`R_{π/2}`** exact |
| **T** | macro **(1-2-1)** (§4.1) **сглаживает** **`C₄`** → **видимый** круг / **`κ=1/√2`** (T1) |
**Квадрат §3.8** — **контур vortex** на coarse, не отмена **локального SO(2)** gate. Тяжёлый vortex может **проступать** на T; **M-закон** **`L_z`** остаётся **дискретным**.

#### 5.2.2 Полная лестница квантования · **`κ_link = 1/|N|`** · **`b ∈ {0,1}`** · **`E ∈ E₀·ℤ`**

##### I · Геометрический квант **`κ_link = 1/|N|`**
На **гекс-срезе (2+1)** каузальная звезда N₆:

**Изотропный** локальный шаг делит перенос **равномерно** по связям. Тогда **одна доля** импульса/фазы/CR-связи на ребро за **`hT`**:
```

```
**Три имени — один квант** (не три fitted параметра):
| символ | слой | роль |
|--------|------|------|
| **`γ`** | M kinetic mix (`bond-unitary`, dispersion) | **`γ = κ_link`** |
| **`cr_strength`** | A9 holomorphy coupling | **`cr_strength = κ_link`** |
| **`ν_CA`** | T emergent viscosity (§4.1.2) | **`ν_CA = κ_link · c₀ · l_P`** (natural: **`κ_link`**) |
**Вывод A15 для `γ`:** не «калибровка ω(k)», а **следствие |N|** + isotropic star. DFT/spectral **сверяет** T, не **задаёт** M.
**Natural units:** **`ν_CA_natural = κ_link`**. **`cr_seed_ceiling = ν_CA · {B_hV}²`** (§3.9.6) — тот же **`κ_link`**, умноженный на Bekenstein-дробь **`{B_hV}`**.
##### II · Энергетический квант **`E₀`** (замыкание лестницы)

### 5.3 Макро-газ: нет «пустого пространства»
**Онтология (не billiard balls):**
| объект | что это в M | что **не** это |
|--------|-------------|----------------|
| **Среда / вакуум** | **непрерывно кипящая** несжимаемая **комплексная спинорная** жидкость **`z∈ℂ²`**; **`K_P ≈ 4.6×10¹¹³` Pa** (§5.1.1) | «пустота между молекулами» |
| **Молекула газа** | **фрактальный macro-узел** (soliton) из **миллиардов** планконов **`hV`** | шарик в пустоте |
| **Макро-газ** | **облако** таких macro-узлов на решётке | сжатие «самой» планковской жидкости |
**Ключ:** при macro-расширении / сжатии **планковская жидкость под облаком не сжимается ни на йоту** (A3, §5.1). Меняется только **плотность распределения macro-вихрей** на **`Λ`**. Молекулы **«плывут»** сквозь **цифровой океан** вакуума.
#### 5.3.1 Уравнение состояния идеального газа **`PV = nRT`**
Macro-молекулы окружены **каузальным фазовым полем** соседей **N**. При сближении — **не механический удар**, а **интерференция Гейзенберговских хвостов** кипения (§3.7, A5).
| macro | M→T смысл |
|-------|-----------|
| **P** | суммарный избыток **`Θ_flow`** / **`Δφ_N`** на границе замкнутого объёма (тор); среда **выталкивает** вихри к гармоническому равновесию |
| **T** | средняя **кинетическая энергия зигзага** macro-вихрей (§5); выше скорость → чаще micro-соударения |
| **V** | число **`hV`**, занятых облаком (не «сжатие жидкости») |
При macro-сжатии (**`V↓`**) вихри сближаются → **Гейзенберг-триггеры** перекрываются → **`Arg(⟨z⟩/z)`** между соседями растёт → **фазовое давление** **`P`** растёт **∝ плотности упаковки**:
```
P = (N_вихрей / V) · k_B · T ⟹ PV = nRT
```
**Менделеев–Клапейрон** — **статистическое следствие** дискретного Коши–Римана + gate (§3.9), **не** отдельная аксиoma M.
#### 5.3.2 Две скорости «звука»: свет **`c`** vs газ **`v_s`** (обе — **T**; на M — **кванты**)
**Сначала M:** ни свет, ни звук **не** «волны». Свет = **`n=0`**, **`E=n_E·E₀`** (§8.2). Звук/акустика = **фононные **`n_k`** на **`Λ`** (§5.2.5) или **пакеты **`p₀`** между macro-узлами**. Ниже — **T-имена** скоростей readout.
В одной модели живут **две разные** гидродинамики **на T**:
| волна | скорость | смысл |
|-------|----------|--------|
| **давление в вакууме (свет)** | **`c = κ·c₀ = c₀/√2`** (CODATA, §1.1) | предел волны **среды** — модуль **`K_P`**, **`n=0`** photon sector |
| **сжатие в macro-газе** | **`v_s = √(γ·R·T/M_газа)`** | передача **механического** импульса **между macro-вихрями** через их соударения |
**Инвариант:** **`v_s ≪ c`** — средняя скорость теплового зигзага macro-вихрей **строго меньше** скорости света из-за **внутренней инерции** зигзага (§5). Звук в газе **ползёт** относительно **света в вакууме**.
#### 5.3.3 Уравнение Ван-дер-Ваальса из геометрии ДА (не fitted)
Классический **реальный** газ:
```
(P + a/V²) · (V − b) = nRT
```
В M **`a`** и **`b`** — **не эмпирика**, а следствия **пиксельной геометрии**, **`K_P`**, **Гейзенберга**, **Паули**, **`α_fs`**.
**1 · Поправка `b` (собственный объём, Heisenberg + Pauli)**
**`b`** — не «объём шариков», а **зона каузального отсечения** **`Δφ ≥ ½`** (§3.7, A16).
Два topo-вихря на **ε** не сближаются бесконечно: при **`R < R_min`** фазовый градиент упирается в **`½` рад** → **`K_P`** + anti-smear → **бесконечное фазовое давление** (самофокусировка), ядра **расталкиваются**.
Минимальный объём локализации планкона: **`hV = l_P³`**. С **Pauli** (§3.10.4) и **N**-ядром:
```
b₀ ≈ 4 · hV = 4 · l_P³
```
Для **`n`** молей, каждая молекула — конгломерат **`N_вихрей`** планконов:
```
b = n · N_A · N_вихрей · 4 · l_P³
```
Сетка **физически** не даёт упаковать macro-вихри плотнее этого предела.
**2 · Поправка `a` (притяжение, фазовая интерференция)**
**`a`** — **минимизация фазового натяжения**: на больших расстояниях **Гейзенберг-хвосты** двух macro-вихрей **интерферируют**; среда тянет дефекты к **`Δ_disc z → 0`** (§3.9). Сила **∝ (N/V)²**, масштаб — **`K_P`**:
```
a = N_A² · N_вихрей² · K_P · l_P⁶ · α_fs
```
**`α_fs`** — константа тонкой структуры (фазовое сопряжение с вакуумом, §8.2 · `si_constants.alpha_fs`).
**3 · Финальное уравнение в терминах автомата**
```
( P + n² N_A² N_вихрей² K_P l_P⁶ α_fs / V² ) · ( V − 4 n N_A N_вихрей l_P³ ) = nRT
```
1. далеко — **притяжение** хвостов (**`a`**, облако «стягивается»);
2. близко — **Heisenberg floor** (**`b`**, дальнейшее сближение **заблокировано**);
3. **нет** NaN / сингулярности — только **максимальное фазовое сопротивление** **`K_P`**.
**4 · Связь с бинарной плотностью §5.0**
**`b`** в continuum — **приближение**. В M — **абсолютный предел заполнения решётки**: macro-газ **не сжимается плотнее **`ρ₀ = ρ_P`**. Когда все **`hV`** в области заняты планконами → **Планковский монолит** → **`K_P → ∞`** (gate) + **Heisenberg floor** → фаза **заблокирована**.
**«Сингулярность» ЧД на M:** не **`ρ → ∞`**, а macro-область, где **каждый пиксель = 1** (вещество). BH = **упакованный монолит **`ρ_P`**, не математический pole плотности.
