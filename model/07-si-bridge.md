### 7.2 Planck-единицы зависят от **c**; **κ** — нет (порядок снизу)
**Исходный интересный ход:** в continuum все Planck-линейки собраны из **(ℏ, G, c)** — **c входит явно**:
$$
\ell_P=\sqrt{\frac{\hbar G}{c^{3}}},\qquad
t_P=\frac{\ell_P}{c}=\sqrt{\frac{\hbar G}{c^{5}}},\qquad
E_P=\frac{\hbar}{t_P}\propto c^{5/2},\qquad
u_P=\frac{c^{7}}{\hbar G^{2}}.
$$
**Скрытое допущение:** **`t_P=\ell_P/c`** уже кладёт **одну** macro-**`c`** и в пространство, и во время — link-speed = **`c`**, т.е. **`κ=1`**.
**M ломает это снизу, не подгоняя c:**
| шаг | откуда | что |
|-----|--------|-----|
| 1 | A1 + FCC + hull при **`a=\ell_P`** | **`κ_{\mathrm{geom}}=R_{\mathrm{in}}/R_{\mathrm{out}}=1/\sqrt{2}`** — **без c** |
| 2 | CODATA **ℏ, G, c** | **`ℓ_P, t_P`** (Planck-лadder **с c**) |
| 3 | геометрия × Planck | **`hT=\kappa_{\mathrm{geom}}\,t_P`**, **`E_0=\kappa_{\mathrm{geom}} E_P`** |
| 4 | алгебра | **`c_0=\ell_P/hT=c/\kappa`**, **`c=\kappa c_0`** — **тождество-проверка**, не определение **κ** |
На гекс-срезе тот же метод: **`κ_{\mathrm{hex}}=\sqrt{3}/2`**, **`hT=(\sqrt{3}/2)\,t_P`**, **`c_0=(2/\sqrt{3})\,c`**, macro **`c`** (CODATA) **тот же**.
```
continuum: t_P = ℓ_P/c ⇒ один тик, один c, κ=1 скрыт
M + geo: hT = κ·t_P ⇒ κ из тела (кубоокtaэдр / гекс)
readout: c = κ·c₀ ⇒ следствие, не корень κ
```
### 7.3 Planck из условий на ячейку (не наоборот)
**Тезис:** планковская **шкала** не «вводится сверху» как `(ℏ,G,c)→ℓ_P,t_P`. **Физика на одном `hV`** + **геометрия FCC** задают лестницу; учебниковый Planck — **слой согласованности** с macro **`c`**, не аксиома **κ**.
**Условия на планковскую ячейку** (§5.0 · §5.0.2 · gate §7.1 · §8.2·geo·voronoi):
| # | условие | формула |
|---|---------|---------|
| G | Voronoy FCC при **`a=ℓ_P`** | **`v_{hV}=ℓ_P³/√2`** |
| P1 | Heisenberg / **`Arg`** | **`s₀=ℏ/2`**, **`E₀=s₀/hT`** |
| P2 | локальный **`E=mc²`** на ячейке | **`m_{\arg}=E₀/c²=m_P/√2`** |
| P3 | плотность ячейки | **`ρ_{\mathrm{cell}}=m_{\arg}/v_{hV}=m_P/ℓ_P³=μ_P`** |
| P4 | gate saturation | **`|z|²=1 ↔ ρ_E=u_P`** |
| P5 | fluid (несжимаемая среда) | **`u_P=μ_P c²`**, **`c²=K_P/μ_P`** |
| P6 | Bekenstein на ячейке | **`B_{hV}=2πE_Pℓ_P/(ℏc\ln2)=2π/\ln2`** (чистое число) |
**Замыкание (без fit):** из P2+P3+G сразу **`μ_P`**, из P5 — **`u_P`**; **`κ`** из hull (§8.2·geo) даёт **`hT=κt_P`**, **`E_P=E₀/κ`**.
**Порядок первичности (M-first):**
```
ℓ_P = a (A1) , hT (M-тик) , s₀=ℏ/2
 ↓ ↓
 v_hV=ℓ_P³/√2 E₀=s₀/hT → m_arg → μ_P
 ↓
 t_P = hT/κ , E_P = E₀/κ (учебниковый Planck — производные)
 ↓
 (ℏ, G, c) CODATA — согласованность абсолютной шкалы, не определение κ
```
**Честная граница:** **метр** в SI всё ещё требует измеренных **`ℏ,G,c`** (или эквивалентного якоря). Но **все ratios** (**`κ`**, **`v_hV/ℓ_P³`**, **`E₀/E_P`**, **`hT/t_P`**, **`ρ_cell=μ_P`**, **`B_hV`**) — **из ячейки + геометрии**, не из «**`c/c₀`** как определения **κ**».
### 7.4 **`a` не может быть иным, чем **`ℓ_P`** (отвязка линейки от **`c`**)
**Тезис:** на M **один** пространственный квант. Геометрическое ребро **`a`** (hull / A1 / Voronoy) **не параметр** — это **`hL`**. Имя **`ℓ_P`** := **`hL`**, не наоборот.
**Цепочка идентичности (не fit):**
| шаг | откуда | что |
|-----|--------|-----|
| 0 | Thm 0.1 (§0) | **`dl = hL`** — ниже нет структуры |
| 1 | A1 | все NN на **одной** длине light-like = **`hL`** |
| 2 | §8.2·geo | выпуклая оболочка 12 NN → ребро **`a = \|NN\| = hL`** |

**Почему нельзя **`a ≠ ℓ_P`****: масштаб **`λa`** либо ломает A1, либо **`dV ≠ v_hV`**, либо требует структуру ниже **`dl`** — запрещено §1.4.
**`√(ℏG/c³)`** — **не определение** **`ℓ_P`**, а **проверка** с macro **`c`**. **`c`** здесь — импорт CODATA, не корень M-линейки.
